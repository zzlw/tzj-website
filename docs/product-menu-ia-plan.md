# 产品线扩容后的导航信息架构（IA）方案

> 背景：产品/产出从现有 5 类扩展到 13+ 类，一级菜单已无法继续平铺。本文给出业内顶级 B2B 制造商的信息架构（IA）做法与落地方案。
> 参考体系：Rosenbauer（产品 + 解决方案双轴 mega-menu）、trainingtowers.com（父页即产品页的钻取结构），结合本站现有「左侧抽屉 + 钻取」交互。

## 二、核心诊断：为什么不能继续平铺

1. **广度爆炸**：13 条产品线若都做一级，加上案例/洞察/关于/资源/联系，一级菜单会到 17+ 项，远超「7±2」可用性阈值，桌面折叠与移动端都会崩。
2. **心智模型混杂**：清单里同时混着三种东西——
   - **建筑主体**（塔、攀登楼、科普馆）
   - **实火/燃烧类**（燃烧室、CFBT、消防模拟）
   - **场景化训练方案**（海事、战术、危化品、绳索、心理拓展）
   - **器械/道具**（配件、抗眩晕器械、竞赛设施）
   直接平铺会让「买一栋楼」和「买一件器械」出现在同一层，语义错位（这正是老菜单「配件里塞训练方案」问题的放大版）。
3. **业内顶级做法**：Rosenbauer、Draeger、MSA 这类宽产品线 B2B，都不做长平铺，而是**「少量顶层 + 分组化 mega-menu / 抽屉」**，并常辅以**「按客户/场景」的解决方案轴**。

## 三、推荐分类模型：4 大产品族（按心智模型收敛）

把 13 条产品线归入 4 个用户一眼能懂的族。这是整套方案的地基，三个菜单方案都基于它。

### A. 训练塔与建筑主体（大型土建/钢构）
- 固定训练塔（钢结构）
- 模块化训练塔
- 公安武警攀登楼训练设施
- 科普教育馆

### B. 实火与燃烧训练（Live-Fire）
- 燃烧室（互锁隔热衬里）
- CFBT 烟火特性训练设施
- 消防模拟训练设施

### C. 专项场景训练（Scenario）
- 海事训练
- 战术训练（公安武警攀登楼的战术科目可交叉引流）
- 危化品训练
- 山岳绳索救援训练
- 心理拓展训练

### D. 训练器械与道具（Equipment & Props）
- 配件与道具
- 体能抗眩晕训练器械
- 竞赛类训练设施

> 4 个族恰好覆盖全部 13 条线，且每族 3-4 项，深度均衡、便于扩展。

## 四、三个落地方案

### 方案 A（推荐）：4 大产品族作为一级，直接复用现有两级抽屉

顶层导航（9 项，与当前 10 项相当，**零 UI 改造**，现有抽屉钻取天然支持）：

```
为什么选我们      ▾ 发展历程 / 核心团队 / 资质认证 / 全球业务
训练塔与建筑      ▾ 固定训练塔（钢结构）/ 模块化训练塔 / 公安武警攀登楼 / 科普教育馆
实火与燃烧训练    ▾ 燃烧室（互锁衬里）/ CFBT 烟火特性 / 消防模拟训练设施
专项场景训练      ▾ 海事 / 战术 / 危化品 / 山岳绳索救援 / 心理拓展
训练器械与道具    ▾ 配件与道具 / 体能抗眩晕器械 / 竞赛类训练设施
工程案例
洞察              ▾ 博客 / 新闻动态
资源与服务        ▾ 如何采购 / 设计中心 / 年检 / 常见问题 / 展会 / 质保
联系我们
```

- **优点**：完全贴合现有「左抽屉 + 一级钻取」交互，无需开发新组件；分类清晰、可无限扩展新产品线（新增只需塞进对应族）。
- **缺点**：一级项 9 个，窄屏靠现有自适应折叠进汉堡（已实现）。
- **适用**：想尽快把新产品线上线、又不想大改前端时的最佳选择。

### 方案 B（最惊艳）：单一「产品与解决方案」超级菜单（Mega-Menu）

顶层收敛到 6 项，最像 Rosenbauer：

```
产品与解决方案    → 展开一张分 4 列的大面板（A/B/C/D 四族并排，每列列出产品）
工程案例
洞察              ▾ 博客 / 新闻
关于拓之迹        ▾ 为什么选我们 / 团队 / 认证 / 全球业务
资源与服务        ▾ 采购 / 设计中心 / FAQ / 年检 / 质保 / 展会
联系我们
```

- **优点**：顶层最干净、最高端；一屏纵览全部产品，最利于交叉浏览与转化。
- **缺点**：需新开发**桌面 mega-menu 面板组件**（现抽屉只支持单列钻取）；移动端仍退化为抽屉多级钻取。
- **适用**：追求品牌质感、愿意投入一次前端开发的中期目标。

### 方案 C（进阶叠加）：产品轴 + 解决方案轴（双轴，B2B 天花板）

在方案 A/B 基础上，再加一条**「按客户/场景」的解决方案入口**，帮不同客户快速自我归类：

```
解决方案（按客户）  ▾ 消防救援 / 公安武警 / 部队 / 矿山救援 / 院校教育 / 企业与园区
```

每个解决方案页把「适合该客户的塔 + 燃烧室 + 专项 + 器械」重新聚合展示（一份产品，两种进入路径）。

- **优点**：命中「我是谁、我该买什么」的真实决策路径，是宽产品线 B2B 的最高级做法。
- **缺点**：需要额外做 6 个解决方案聚合页（内容可复用产品页片段）。
- **建议**：作为方案 A/B 上线后的第二阶段增强。

## 五、路由与页面规划（新增产品线）

统一放在语义清晰的分组路径下，便于 SEO 与维护：

| 产品线 | 建议路径 | 归属族 |
|--------|----------|:--:|
| 公安武警攀登楼 | `/fixed-tower/climbing-tower` 或 `/towers/climbing` | A |
| 科普教育馆 | `/buildings/education-center` | A |
| CFBT 烟火特性训练设施 | `/burn-rooms/cfbt` | B |
| 消防模拟训练设施 | `/burn-rooms/fire-simulation` | B |
| 山岳绳索救援训练 | `/specialized-training/rope-rescue` | C |
| 心理拓展训练 | `/specialized-training/psychological` | C |
| 体能抗眩晕训练器械 | `/accessories/fitness-equipment` | D |
| 竞赛类训练设施 | `/accessories/competition` | D |

> 若采用方案 A，建议把 URL 分组与「4 大族」对齐（如统一 `/towers`、`/live-fire`、`/scenario`、`/equipment` 前缀），SEO 结构更清爽——这是一次性重构，需权衡老链接跳转。

配套改动清单：
- `apps/web/src/components/layout/Header.tsx` → 重写 `NAV_ITEMS`
- `apps/web/src/components/layout/Footer.tsx` → `FOOTER_LINKS` 按 4 族对齐
- `apps/web/src/lib/routes.ts` + `sitemap.ts` → 登记新页面
- 新增各产品线页面（可复用 `blocks.tsx` 的 StatBand / FeatureGrid / ProcessBand / RelatedLinks / CtaBand，快速成型）

## 六、建议路线

1. **第一步（本周）**：采用**方案 A**，先把 4 大族的菜单骨架落地——即使部分新产品页还没写，也可先建「族总览页 + 占位卡片」。
2. **第二步**：逐个补齐 8 个新产品线页面（用现有可复用区块，效率高、风格统一）。
3. **第三步（中期）**：升级为**方案 B** 的桌面 mega-menu，提升品牌质感。
4. **第四步（进阶）**：叠加**方案 C** 的「按客户解决方案」轴，形成双轴导航，达到业内天花板。

---

## 七、待你拍板的 3 个决策点

1. **「钢结构训练塔」是否并入「固定训练塔」**（推荐并入，避免重复）。
2. **先走方案 A 还是直接上方案 B**（推荐先 A、后 B）。
3. **URL 是否借机重构为 4 族前缀**（影响 SEO 与老链接，需权衡）。
