# Design System

## 排版体系

| 级别 | 大小 | 用途 |
|------|------|------|
| Eyebrow | 12px, 大写, 红色, letter-spacing 0.2em | Section 标签 |
| H1 | 48-64px, bold, 白色 | Hero 标题 |
| H2 | 32-40px, medium bold | Section 标题 |
| H3 | 20-24px | 卡片标题 |
| Body | 16-18px, #B8B8B8 | 正文/次要文字 |

## 交互模式

- Header: 透明叠加 → 滚动后实色深色
- 产品分类: 水平滑动卡片 (大图 + 底部文字标签 + 红色箭头)
- 新闻: 三列卡片网格
- CTA: 文字链接为主，简洁优雅
- 图片: blur-up 占位符加载效果
- Footer: Newsletter 订阅横幅 + 5列导航 + 版权

## Section 间距

- Section 间: 96px (6rem)
- 内容区最大宽度: 1280px (80rem)
- 内边距: 24px (移动端), 48px (桌面端)
