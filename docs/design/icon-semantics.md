# Admin 图标语义表

> 原则：**一个动作一个图标，一个图标一种语义**。新增操作按钮前先查此表；表内没有的动作再挑新图标，并回填此表。
> 图标库：`lucide-react`。落地自 admin-ui-polish-plan.md B3。

## 行动作（表格/列表行内按钮）

| 动作 | 图标 | 说明 |
|------|------|------|
| 阅读 | `BookOpen` | 进入后台内部阅读页（如文档中心 `detailPath`） |
| 预览 | `Eye` | 打开只读预览（前台效果预览、媒体预览） |
| 查看 / 查看详情 | `Eye` | 打开详情抽屉/弹窗（与预览同属"打开只读视图"语义族） |
| 编辑 | `Pencil` | 进入编辑表单 |
| 删除 | `Trash2` | 删除（需确认弹窗） |
| 发布 | `Send` | 内容发布上线 |
| 撤回 | `Undo2` | 已发布内容撤回为草稿 |
| 恢复 / 重置 | `RotateCcw` | 恢复默认值、重新打开会话等 |
| 转化客户 | `UserRoundPlus` | 访客/询盘转化为客户 |
| 已转化标识 | `UserRoundCheck` | 只读状态标识（非动作） |

## 通用操作

| 动作 | 图标 | 说明 |
|------|------|------|
| 新建 | `Plus` | 列表页头部主操作 |
| 新建文档（写作） | `PenLine` | 仪表盘欢迎行快捷入口；区别于 `Pencil`（编辑既有内容） |
| 搜索 | `Search` | 搜索输入框前缀 |
| 清除 / 关闭 | `X` | 清除筛选、关闭浮层 |
| 上传 | `Upload` | 文件/媒体上传 |
| 更多 | `MoreHorizontal` | 收纳次要动作的下拉菜单 |

## 状态与指标（非动作，允许与动作图标复用语义族）

| 场景 | 图标 | 说明 |
|------|------|------|
| 阅读次数 | `Eye` | 指标展示（"被查看"语义），非动作 |
| 正在查看对话 | `Eye` | 客服在线状态标识 |
| 已读回执 | `Check` / `CheckCheck` | 聊天消息回执 |
| 未读标记 | 红点（无图标） | 见 CONVENTIONS「红点 UI 语义」 |

## 禁止事项

- ❌ 同一动作在不同页面使用不同图标（如"编辑"混用 `Pencil` / `Edit3`）；
- ❌ 同一图标承担两种**动作**语义（历史问题：「阅读」「预览」曾共用 `Eye`，已于 B3 修正为 `BookOpen` / `Eye`）；
- ❌ 引入与现有图标视觉过近的新图标（如 `Edit` vs `Pencil`、`Eye` vs `ScanEye`）。
