# 2026 百度推广链接全新策略方案

> 编写日期：2026-08-03
> 背景：旧站（PHP 静态站 `proshow-*.html`）已下线，新站（Next.js 响应式）上线。
> 本方案**完全废弃旧推广链接**，基于 2026 行业趋势、百度搜索意图和新站路由，
> 从零重建推广方案结构。PC/移动端统一使用同一 URL（新站响应式）。

## 一、市场背景与策略依据

### 1.1 行业趋势（2025-2026）

- 全球消防应急救援设备市场 CAGR ≈ 4%，2026 年预计 71.6 亿美元（至 2035 年达 102.7 亿）
- 国务院"十五五"应急体系建设规划明确：**完善训练设施、配备专业装备**
- 国家消防救援局科技计划 2026 年度重点：灭火救援技术与装备
- 训练塔采购招标活跃（单项目 46-77 万），政府/消防/部队/院校多线需求
- 行业趋势：**模块化、标准化、智能化**训练设施
- 2026 年训练塔厂家选型指南发布（gongkong.com），头部企业走标准化/模块化路线

### 1.2 百度搜索热词分析

| 关键词方向 | 搜索意图 | 竞争度 |
|-----------|---------|--------|
| 训练塔、消防训练塔 | 产品通用词 | 高 |
| 消防训练塔厂家、训练塔生产厂家 | 采购决策词 | 中高 |
| 模块化训练塔、集装箱训练设施 | 新品类词 | 中（上升） |
| CFBT 真火训练、烟火特性训练 | 专业细分词 | 中低（上升最快） |
| 双窗训练塔、框架式训练塔 | 规格词 | 中 |
| 消防训练基地建设 | 解决方案词 | 中 |
| 攀登楼训练设施、攀岩墙 | 专项需求词 | 低 |
| 绳索救援训练、山岳救援 | 专项需求词 | 低 |
| 心理行为训练设施 | 专项需求词 | 低 |

### 1.3 策略核心原则

1. **搜索意图 → 落地页精准匹配**（提升百度质量度 + 转化率）
2. **PC/移动端统一 URL**（新站响应式，不再区分设备）
3. **商业意图优先**（采购词 > 产品词 > 信息词）
4. **UTM 全链路追踪**（后台访客分析直接归因到计划/单元/关键词）
5. **分层投放**（高意图先投、细分赛道低成本获客）

## 四、UTM 参数规范（统一模板）

所有百度创意/关键词的最终访问 URL 统一拼接：

```
https://www.tzjii.com/zh-CN/{落地页}?utm_source=baidu&utm_medium=cpc&utm_campaign={方案名}&utm_content={单元名}&utm_term={keywordid}
```

### 参数说明

| 参数 | 取值规则 | 示例 |
|------|---------|------|
| `utm_source` | 固定 `baidu` | `baidu` |
| `utm_medium` | 搜索推广固定 `cpc`；信息流用 `display` 或 `cpm` | `cpc` |
| `utm_campaign` | 方案名称（中文） | `训练塔-固定式` |
| `utm_content` | 单元名称（中文） | `钢结构词` |
| `utm_term` | 百度关键词通配符 `{keywordid}` | `{keywordid}` |

> 注意：
> 1. `{keywordid}` 回传的是**数字 ID** 而非词面，admin 后台归因分析时需到百度后台
>    「关键词报告」按 ID 对照词面（或导出关键词列表建立 ID→词面映射表）。
> 2. 落地页路径**不带尾斜杠**（见 6.4），UTM 直接以 `?` 拼接。

### 示例

```
https://www.tzjii.com/zh-CN/fixed-tower?utm_source=baidu&utm_medium=cpc&utm_campaign=训练塔-固定式&utm_content=钢结构词&utm_term={keywordid}
```

### `utm_medium` 取值约束

后端按**白名单精确匹配** medium：
- `cpc` / `ppc` / `paid` / `paidsearch` → 归为"付费（paid）"
- `display` / `cpm` / `banner` → 归为"付费（paid）"
- 其他值（如 `feed`、中文、拼错）→ 归成"引荐（referral）"

**规则**：搜索推广统一用 `utm_medium=cpc`；信息流用 `utm_medium=display` 或 `cpm`。
若已开 OCPC、URL 带了 `bd_vid`，则无论 medium 填什么都会被强制归为付费。
