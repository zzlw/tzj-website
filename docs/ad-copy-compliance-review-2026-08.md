「易引起投诉、撤诉麻烦、罚金不低」——**程序与成本判断基本合理**：广告违法投诉/举报门槛低，企业举证与沟通成本往往高于改几个字的成本。因此：**有疑点优先改文案，而不是赌「不会被盯上」。**

**2026 监管新动向（摘要）**：《广告法》正文近年未重写，但市监总局于 **2026-06-12** 发布《广告引证内容执法指南》（2026 年第 20 号），叠加 2023《广告绝对化用语执法指南》、2026 年提示性用语整治——对「数据无出处」「萝卜坑式第一/最高」「大小字免责」查处更细、举证更严。官网自设媒介广告同样适用。

## 二、法律依据要点（含 2026 口径）

### 2.1 《广告法》常用条款

| 条款 | 核心要求 | 与本站排查的对应 |
|------|----------|------------------|
| 第 4 条 | 广告不得含有虚假或引人误解的内容 | 数据不实、夸大可信度 |
| 第 8 条 | 对性能、质量、允诺等应准确、清楚、明白 | 「质量保证」「责任到底」等允诺须与合同/质保一致 |
| 第 9 条（三） | 禁止「国家级」「最高级」「最佳」等用语（含近似表述） | 「最坚固 / 最优 / 最佳 / 市场最高 / 唯一」等 |
| 第 9 条（二） | 不得使用或变相使用国家机关及其工作人员名义或形象 | 客户行业称「消防/公安/部队」作受众描述一般可接受；禁止暗示「官方指定/推荐」 |
| 第 11 条 | 数据、统计、调查、文摘、引用语等须真实准确并表明出处；有范围/期限须明示 | 「16 年」「1000+」「31 省」「多项专利」 |
| 第 28 条 | 虚假或引人误解即虚假广告 | 夸大品质、伪造规模、片面比较 |

### 2.2 2023–2026 配套执法指引（实务比「法条原文」更常被引用）

| 文件 | 对本站的含义 |
|------|----------------|
| 《广告绝对化用语执法指南》（2023） | 「最 / 最佳」等并非机械一律罚；但**指向所推销商品/服务且具误导或贬低同行效果**时仍适用禁令。未指向商品的理念口号、技术参数客观描述等可豁免。 |
| 《关于强化广告中提示性用语监管工作的通知》（2026 年相关整治） | 加大对「第一 / 首创 / 最佳 / 领先」等提示性用语监管；细分赛道「第一」易被认定为引人误解。 |
| 《广告引证内容执法指南》（市监总局 2026 年第 20 号，2026-06-12 公布） | **广告主对引证内容真实性、准确性、合法性负责，并依法承担举证责任**；自证数据也须真实、可验证；禁止「大字吸睛、小字免责」式限缩；用「最高级 / 最佳 / 销量第一」做引证宣传时，「萝卜坑」式地域/行业切分**不再享受**绝对化用语豁免。 |

补充：B2B 工业品站、官网自媒体、百度推广落地页**同样适用**；「我们是对公业务」**不能**作为免责理由。

## 三、分项评估

### 3.1 「16+ 年行业深耕」「1000+ 训练基地项目/案例」

#### 网站实际出现位置（抽样）

- 首页 Mission 数字条：`16+` / `1000+`（`MissionSection` + `zh-CN/home.json`）
- SEO / 站点描述：`site.ts`、`zh-CN.json` 的 `siteDescription`
- 案例页、全球业务、发展历程、新闻稿「突破 1000 个」等多处重复

#### 评估

1. **出处义务（第 11 条）**  
   AI 说法正确：页面上把「16 年」「1000+」当作经营规模/历史的**确定性宣传**，却未见第三方审计、合同清单、可点击的统计口径说明。即便数字真实，**不标明出处**也构成合规瑕疵；数字不实则上升为虚假宣传。

2. **「16 年」与工商事实的张力（关键风险点）**  
   公开工商信息（多源一致）：河南拓之迹实业有限公司成立于 **2018-10-08**。至 2026 年主体存续约 **8 年**，并非 16 年。  
   - 若文案被理解为「本公司已成立/经营 16 年」→ **虚假宣传风险很高**。  
   - 若本意是「创始团队/核心骨干从业经验合计或累计 16 年」→ 必须**改成可核验、不误导主体年限**的表述，并准备人事/履历类内部依据；不能继续写「公司 16 年」。

3. **「1000+」**  
   - 站内有新闻口径「累计突破 1000 个」，案例列表仅展示少量代表性项目。  
   - 关键不在「能不能写大约数」，而在：**有没有内部台账/合同/交付清单能对上**，以及对外是否说清统计口径（已交付 / 含设计 / 含配套等）。  
   - 若无法举证，应下调或改为「多项」「众多」等非精确量化，或仅在有出处的新闻/白皮书中发布并链到出处。

#### 建议处置（优先）

| 优先级 | 动作 |
|--------|------|
| P0 | 停用或改写所有「16 年 / 16+ / 十六年」对公司主体的暗示；改为「成立于 2018 年」或「团队深耕应急救援训练装备多年（内部口径另定）」 |
| P0 | 梳理「1000+」是否可举证；不能举证则改为「数百个」「覆盖多省」等，或补「数据口径 + 更新日期 + 内部统计出处」说明 |
| P1 | 案例页避免「超过 1000」与少量案例列表形成反差误导；可写「部分代表性项目如下」 |

### 3.2 「严苛标准，值得信赖」

#### 网站实际出现位置（抽样）

- 首页区块标题（`zh-CN/home.json` → trust 相关）
- 资质认证页描述、价值主张中的「严苛的认证流程」
- 多处「值得信赖的伙伴」

#### 评估

- AI 引用第 28 条「引人误解」的路径**说得通**，但执法上对「严苛」「值得信赖」的打击强度，通常**低于**「最佳 / 第一 / 顶级」。
- 「严苛」本身不是第 9 条列举的绝对化禁词；风险主要来自**无法客观验证却暗示显著优于同行**。
- 本站已有 **ISO 9001、高新技术企业、安全生产标准化** 等可核验表述（资质页）——更稳妥的做法是**让客观认证当主角**，少用主观形容词。

#### 建议处置

| 原文倾向 | 建议替换 |
|----------|----------|
| 严苛标准，值得信赖 | 通过体系认证，质量可控 / 以 ISO 等认证体系保障交付质量 |
| 严苛的认证流程 | 完整的体系认证与持续改进流程 |
| 值得信赖的伙伴 | 长期合作的交付伙伴 / 可追溯的全流程服务 |

### 3.3 「单一对接，责任到底」

#### 网站实际出现位置（抽样）

- CTA / 区块描述（`blocks.json`、`blocks.tsx` 默认文案）
- FAQ、新闻、团队页等处的「单一对接」

#### 评估

- 「单一对接」语义接近「一个接口」，**不等于**广告法明文禁止的「唯一」「首个」等，AI 将其直接等同「唯一」**略有放大**。
- 但在严格审查或竞争对手投诉场景下，仍可能被解读为「只有我们能一站搞定 / 唯一责任主体」类暗示。  
- **改写成本极低，建议直接改**，不必纠结法条边界。

#### 建议处置

| 原文 | 建议 |
|------|------|
| 单一对接，责任到底 | 一站式对接，全程跟进 / 专人对接，权责清晰 |
| 单一对接 | 一站式服务 / 统一项目对接人 |

## 四、对「投诉难撤、罚金不低」的判断

| 说法 | 评价 |
|------|------|
| 不当措辞易引起投诉 | **合理**。竞品、消费者、职业打假人均可能以广告违法举报。 |
| 申请撤诉/沟通麻烦 | **合理**。即便最终不罚或从轻，应对成本（时间、材料、公关）往往高于改文案。 |
| 罚金不低 | **视情节**。《广告法》对虚假广告有明确罚款幅度；「严苛」「单一」单独被重罚的概率通常低于「虚假数据年限」，但叠加投诉与舆情后成本不可忽视。 |

**建设与对外宣传「慎之又慎」——这条态度建议采纳。**

## 六、不建议的做法

1. **只删中文、英文保留 1000+**——双语不一致仍可被截图举报。  
2. **脚注写「数据仅供参考」却继续用精确大数字当主视觉**——不能替代第 11 条的真实与出处要求。  
3. **用「行业惯例都这么写」抗辩**——广告法审查看的是本广告是否真实、是否误导。  
4. **只改 Mission、不改 StatBand / 新闻 slug / 英文**——等于没改完。  
5. **官网已改、百度创意仍写「16 年 / 最坚固」**——风险平移到投放素材。  
6. **继续空转扩写本文**——执行粒度已够（§11.11）；下一步是拍板与改代码。

### 10.6 与 2026《引证指南》对照的专项提醒

1. **「1000+」「31 省」** 属可验证事实信息：要么拿得出统计方法与台账，要么不要写精确数。脚注「仅供参考」**不能**替代真实与出处。
