## 每个人都要做的事（通用检查项）

不管管哪摊，每个页面都要过这 8 条：

1. 页面能打开，不白屏、不一直转圈、不报错
2. 图片正常显示，不裂开、不模糊
3. 文字正常，不乱码、不重叠、不串行
4. 页面上的按钮、链接都能点，点了能跳到该去的地方
5. 顶部语言切换成 繁体/英文 后，内容跟着变，不出现中文页面里夹着英文
6. 浏览器窗口缩到手机宽度（或按 F12 切手机模式），排版不乱七八糟
7. 点"返回"能正常回到上一页
8. 页面底部有"预约咨询/联系我们"的话，按钮能点开

## 发现问题怎么报（格式）

```
页面：哪个页面
操作：点了什么/做了什么
现象：出现了什么（截图，把问题位置圈出来）
```

- **大问题**（页面打不开、按钮点了没反应、乱码、数据错）：当天在群里说，先修
- **小问题**（错别字、间距、颜色、图片不清晰）：截图记下来，统一报

## 怎么样算测完了

- 负责的页面全部过一遍，8 条检查项都勾过
- 发现的问题都按上面格式报过了
- 每周五把"测了几个页面/发现几个问题"发群里

## 公平怎么保证

1. 页面数大家差不多（13~20 个）；Acy 页面少但表单、聊天、搜索每个都要反复测，活儿一样重
2. 语言切换、手机宽度检查人人做，不是谁的专属活
3. 每周五轮一个人做「全站大巡检」（所有页面切三种语言 + 手机宽度过一遍），5 周轮完，人人一次
4. 谁发现问题谁报，群里公示，不存在谁干多干少
