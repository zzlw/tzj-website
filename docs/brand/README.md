# Brand Guidelines

拓之迹（TZJ）品牌视觉识别系统 — Rosenbauer 工业浅色风格。

## 品牌色

- **品牌红** `#E3000F` — CTA 按钮、Eyebrow 标签、选中态强调
- **品牌红（可访问）** `#B8000C` — 小字/链接（满足 WCAG AA 白底对比度）
- **背景** `#FFFFFF` — 主背景色
- **表面色** `#F7F7F7` — 卡片、面板、次要区域
- **边框** `#E8E8E8` — 分割线、输入框
- **主文字** `#1C1C1C` — 标题、正文
- **次要文字** `#5B6166` — 描述、辅助信息

## 设计灵感

- **Rosenbauer** (rosenbauer.com) — 白底工业浅色风格、锐利边角、流体大标题、品牌红强调
- **WHP Training Towers** (trainingtowers.com) — 信息架构、产品钻取结构

## 字体

- **展示字体**: Archivo（标题、大字号）
- **正文字体**: Geist（UI 文字、正文）
- **中文回退**: PingFang SC → Microsoft YaHei → Noto Sans SC

## Logo 使用

- 默认使用深色 Logo
- Header 滚动后保持深色 Logo（浅色背景）
# Brand Guidelines

拓之迹（TZJ）品牌视觉识别系统。

## 品牌色

- **品牌红** `#E60012` — 仅用于 Eyebrow 标签、CTA 按钮、分类标识
- **深背景** `#111215` — 主背景色（85% 深色区域）
- **表面色** `#1B1C20` — 卡片、面板背景
- **边框** `#2B2C31` — 分割线、边框
- **白文字** `#FFFFFF` — 标题、主文字
- **灰文字** `#B8B8B8` — 次要文字、描述

## 设计灵感

- **Rosenbauer** (rosenbauer.com) — 深色工业调性、全屏 Hero、品牌红强调
- **WHP Training Towers** (trainingtowers.com) — 信息架构、Bento Grid、SVG Shape Divider

## Logo 使用

- 浅色背景使用深色 Logo
- 深色背景使用白色 Logo
- Header 透明状态使用浅色版，滚动后切换深色版
