### 身份与角色
- 生产环境媒体/静态资源的权威源，桶名 `tzj-media-static-assets`（cn-beijing），前缀包含 `cases/ content/ images/ products/ statics/ trade-shows/ uploads/ videos/`。
- 本地开发使用 MinIO（`localhost:9000`，bucket `tzj-uploads-dev`）作为 S3 兼容替代。

### 集成方式
- API 通过 `@aws-sdk/client-s3` 访问（path-style，endpoint 由环境变量配置）。
- 恢复脚本 `apps/api/scripts/restore-media-to-minio.mjs` 复用项目自带 S3 客户端将 OSS 数据导入本地 MinIO。
- 媒体 URL 统一指向 `S3_PUBLIC_DOMAIN`，ECS 仅跑 Docker/nginx 不存原图。

### 关键约束
- 远程 ECS 服务器不可从本地直接访问（SSH 凭据仅在 GitHub Secrets），但媒体恢复无需服务器——直接从 OSS 拉取即可。
- 本地数据库清理后需同时恢复 OSS 对应 bucket 的数据，否则媒体链接断裂。

### 验证
- 恢复流程已验证：`aliyun oss cp -r` 下载 → Node 脚本上传至 MinIO → Prisma db push 补齐 schema → 媒体 URL 全部可解析。
