### 询盘
- 定义：官网访客通过联系表单提交的咨询信息，存储在 Contact 表中。每个询盘包含访客匿名 ID（visitorId）、来源渠道、联系方式等，是 B2B 销售漏斗的第一环节。询盘可转为客户线索（Customer），并关联访客画像进行归因分析。
- 别名：contact、inquiry

### 访客ID
- 定义：持久匿名访客标识符（_tzj_vid），存储在浏览器 localStorage 中，用于跨会话追踪同一浏览器的访客行为。与埋点系统同源，是访客分析、询盘归因、客户转化的核心关联键。
- 别名：visitorId、_tzj_vid、anonymousId

### 转为客户线索
- 定义：将询盘（Contact）或聊天会话（ChatRoom）转化为正式客户记录（Customer）的业务流程。支持幂等去重（通过 contactId/chatRoomId/visitorId），可设置公海/私海归属，并保留完整的归因链路。
- 别名：convert to lead、lead conversion

### 公海客户
- 定义：未分配给具体坐席的客户池（ownerId 为空），任何坐席均可认领。与私海客户（ownerId 指向某坐席）共同构成 CRM 的公私海模型，支持 claim/release/transfer 流转。
- 别名：public pool customers、open sea customers

### 私海客户
- 定义：已分配给特定坐席的客户（ownerId 指向该坐席），属于该坐席的专属客户池。坐席可对私海客户进行跟进、转化等操作，也可将其放回公海供其他坐席认领。
- 别名：private pool customers、my customers

### 访客画像
- 定义：基于访客行为数据构建的完整档案，包括地区（IP 定位）、设备信息、流量来源、UTM 营销归因、浏览行为、首末访问时间等。通过读取时 IP 重解析获取精确地理位置（省市区+运营商）。
- 别名：visitor profile、visitor insight

### 访客中心
- 定义：后台管理系统中的访客数据分析模块，提供按访客和按 IP 两个视角的访客明细表格，支持搜索、排序、分页等功能。可点击访客 ID/IP 查看详细的访客画像抽屉。
- 别名：visitor center、visitor analytics

### 访客分析
- 定义：后台管理系统中的访客统计分析模块，展示 PV/UV 趋势、热门页面、地区分布、来源渠道、设备分布等可视化图表。支持自定义时间范围和粒度切换（小时/天/周/月）。
- 别名：visitor analytics、traffic analytics

### 在线客服
- 定义：实时聊天客服系统，支持访客与坐席的即时沟通。包含会话管理、访客信息查看、消息搜索、会话转接等功能。会话状态包括 waiting/closed/archived 等。
- 别名：live chat、customer service

### 会话接管
- 定义：坐席主动接手他人负责会话的操作。与"转接给同事"不同，接管是单方面的动作，会留下系统记录并通知原负责人。适用于紧急情况下快速响应访客需求。
- 别名：take over session、session takeover

### IP 封禁
- 定义：安全功能，通过哈希存储封禁恶意 IP 地址，阻止其访问所有 API 接口。支持临时封禁（expiresAt），管理员可在后台管理封禁名单。封禁后用户看到 403 Forbidden 错误。
- 别名：IP blocking、IP ban

### 水印功能
- 定义：后台管理系统的安全功能，在屏幕上叠加半透明水印（包含登录账号、日期等信息），防止员工截图泄露公司信息。支持全局开关和透明度配置，通过站点设置管理。
- 别名：watermark、anti-screenshot

### URL-state
- 定义：前端状态管理最佳实践，将表格的搜索、筛选、分页、排序等状态持久化到 URL 参数中，支持刷新不丢失、分享链接、浏览器前进后退等功能。通过 useUrlState hook 统一管理。
- 别名：URL state、state persistence

### ResourceListView
- 定义：共享的列表视图组件，提供统一的搜索、筛选、分页、排序功能。支持活动筛选芯片、命中结果计数、清除按钮等交互，被多个内容模块复用。
- 别名：list view、resource list

### 访客抽屉
- 定义：通用的访客信息展示组件，在任何地方点击访客 ID 或 IP 时弹出，显示完整的访客画像、浏览行为、聊天记录等信息。支持二级抽屉层级管理。
- 别名：visitor drawer、visitor panel

### 未读标记
- 定义：询盘管理列表中联系人姓名前的红色圆点标记，表示该询盘尚未被任何人查看过。点击查看后自动置为已读，红点消失。与"待处理/已处理"状态独立。
- 别名：unread marker、red dot
