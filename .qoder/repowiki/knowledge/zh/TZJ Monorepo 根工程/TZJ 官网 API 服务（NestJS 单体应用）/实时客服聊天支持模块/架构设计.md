模块以 `support.module.ts` 为 NestJS 模块入口，统一注册 HTTP 控制器（`SupportController`、`ChatRoomController`）与 WebSocket 网关（`ChatGateway`），并通过 DI 暴露 `SupportService`、`ChatRoomService`、`ChatGateway`、`ChatAuthService` 供外部使用。

- 分层结构：HTTP 层由两个 Controller 暴露 REST API；业务逻辑集中在 `ChatRoomService`、`SupportService`；安全鉴权由 `ChatAuthService` 独立封装（签发/校验 chat token、用业务 access token 兑换坐席 chat token）；实时通信由 `ChatGateway` 处理所有 socket.io 事件（连接握手、房间加入/离开、发消息、标记已读、状态更新等）。
- 在线状态通过 `ChatPresenceStore` 抽象，默认 Redis 实现（多实例共享），未配置 `REDIS_URL` 时回退内存模式，配合 `@socket.io/redis-adapter` 实现跨实例广播。
- 消息全文检索通过 `MessageSearchService` 抽象接口 + `PgTrgmMessageSearchService` 当前实现（pg_trgm GIN 索引），未来可无缝替换为 Meilisearch 等后端。
- 依赖方向单向：Controller → Service → Gateway/Store/Auth，Gateway 反向调用 Service 完成持久化，避免循环依赖。
- 测试文件（`.integration.spec.ts`、`.spec.ts`）覆盖 gateway presence、visitor presence、conversation lifecycle 等关键路径。
