- 每个设置域拆分为 defaults、schema、service 三个文件，defaults 导出 DEFAULT_* 常量、merge* 合并函数与 normalize* 数据清洗函数。
- 更新接口统一先通过对应 schema 的 `safeParse` 校验，失败抛出 `BadRequestException(parsed.error.flatten())`，再通过 `prisma.setting.upsert` 按 key 写入。
- Controller 方法通过 `@RequirePermissions` 装饰器声明权限（view/manage），公开只读接口使用 `@Public` 装饰器绕过鉴权。
- URL/路径类字段在入库前通过 normalize* 函数剥离 S3_PUBLIC_DOMAIN 前缀，确保数据库只存相对对象 key。
- Favicon 处理采用多阶段流程：MIME 类型判断 → 必要时 sharp 缩放 + png-to-ico 转换 → S3 上传主文件与可选预览文件，错误统一转为 BadRequestException。
