模块由两个子目录组成：`settings/` 暴露 SettingsModule（NestJS @Module），聚合 SettingsController 与 SettingsService；`site-settings/` 提供独立的 FaviconController 与 FaviconService，两者均被 SettingsModule 通过 imports 注册。
- Controller 层仅做路由声明与权限装饰（`@Public`、`@RequirePermissions('settings.manage'|'settings.view')`、`@ApiBearerAuth`），业务逻辑全部委托 Service。
- SettingsService 依赖 PrismaService 和 ConfigService，通过 `prisma.setting.upsert` 以 key（如 `site.public`、`site.media`、`site.notifications`）为唯一标识持久化 JSON value。
- 每个设置域（public/media/notifications）采用三文件模式：`.defaults.ts` 定义默认值与 merge/normalize 函数，`.schema.ts` 用 Zod 定义校验规则，service 中先 `safeParse` 再 upsert。
- FaviconService 直接依赖 S3Service，使用 sharp + png-to-ico 完成图片格式转换，并分别存储 `.ico` 主文件与 `.png` 预览文件。
- 依赖方向：controller → service → (PrismaService / S3Service / ConfigService)，settings.defaults 之间可互相引用（如 notifications.defaults 引用 public.defaults 的邮箱）。
