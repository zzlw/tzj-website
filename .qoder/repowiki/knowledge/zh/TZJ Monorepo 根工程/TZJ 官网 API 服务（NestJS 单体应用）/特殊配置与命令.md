开发：`npm run dev`（nest start --watch）；构建：`npm run build`；类型检查：`npm run typecheck`；测试：`npm run test` / `npm run test:cov` / `npm run test:e2e`；数据库：`npm run prisma:generate`、`npm run prisma:migrate`、`npm run prisma:seed`、`npm run prisma:studio`；种子脚本：`npm run seed:contacts:mock`、`seed:visitors:mock`、`seed:chat:mock`、`seed:customers:mock`。
