入口 main.ts 启动 NestFactory，注册全局中间件（requestId、helmet、compression）、全局前缀 api/v1、CORS、ValidationPipe 与 Swagger 文档；app.module.ts 作为根模块集中 import 所有业务 Module（Auth、Access、Users、Blogs、News、Cases、Pages、TradeShows、Contact、Customers、Documents、Media、Storage、Support、Analytics、Audit、Security、Settings、Integrations、Notifications、System、Health 等），并通过 APP_GUARD/APP_INTERCEPTOR/APP_FILTER 注入全局限流、JWT 鉴权、IP 封禁、角色控制、响应包装、审计日志与异常过滤。
- 数据层：PrismaModule 提供 PrismaClient 单例，所有业务模块通过各自 Service 依赖 Prisma 客户端访问 PostgreSQL。
- 配置层：ConfigModule.forRoot 从 .env.local/.env/../../.env 加载环境变量，validateEnv 校验必填项。
- 横向能力：common 目录提供跨模块复用的过滤器、拦截器、中间件、工具函数（slug/markdown/sanitize/client-ip 等）；prisma/ 存放 schema.prisma 与迁移脚本；scripts/ 提供种子数据与运维脚本。
- 运行时：Socket.IO + Redis Adapter 为 support_chat 模块提供分布式 WebSocket 支持；@nestjs/throttler 实现全局限流；@nestjs/schedule 提供定时任务。
