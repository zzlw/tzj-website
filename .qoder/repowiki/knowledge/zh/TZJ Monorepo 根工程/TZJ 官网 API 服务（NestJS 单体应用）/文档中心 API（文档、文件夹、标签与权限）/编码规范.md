- Controller 方法统一使用 `@RequirePermissions('docs.view|create|edit|delete|manage')` 装饰器声明操作级权限，并通过 `@CurrentUser()` 注入当前用户上下文。
- Service 对数据库异常统一抛出 NestJS 内置异常（`BadRequestException`、`NotFoundException`、`ForbiddenException`、`ConflictException`），并以中文消息描述错误原因。
- 所有对外输入 DTO 同时标注 `@ApiProperty`（Swagger）与 class-validator 装饰器（`IsString`、`IsEnum`、`MaxLength` 等），实现校验与文档一体化。
- 涉及多步写操作的 Service 方法（如标签重命名、合并、删除）使用 `this.prisma.$transaction` 保证原子性。
- slug 生成统一走 `slugifyTitle` + `ensureUnique*Slug` 模式，通过循环追加 `-n` 后缀保证唯一性。
- 个人文档与组织文档通过 `ownerId` 字段区分：`ownerId` 非空表示个人文档，空表示组织文档，并在权限检查中分别处理。
