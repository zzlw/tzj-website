- Controller 方法通过装饰器组合鉴权（`@RequirePermissions`）、认证（`@ApiBearerAuth`）与 Swagger 注解（`@ApiOperation`、`@ApiQuery`）声明接口元数据。
- DTO 统一使用 class-validator 装饰器（`@IsString`、`@IsEmail`、`@MinLength`、`@MaxLength`、`@IsOptional` 等）配合 `@ApiProperty` / `@ApiPropertyOptional` 同时实现校验与文档。
- Service 层对数据库异常通过显式抛出 NestJS 内置异常（`NotFoundException`、`ConflictException`、`BadRequestException`、`ForbiddenException`、`UnauthorizedException`）进行错误映射。
- 敏感字段（password）在创建与更新时统一通过 `bcrypt.hash(dto.password, 12)` 加密后再写入数据库。
- 涉及角色或状态变更的操作会调用 `revokeSessions` 批量撤销该用户未过期的会话，保证安全一致性。
