采用 NestJS 标准三层结构：`users.module.ts` 作为模块入口注册 `UsersController` 和 `UsersService`；`users.controller.ts` 通过 `@Controller('users')` 暴露 RESTful 路由（GET/POST/PUT/DELETE），并使用 `@RequirePermissions('users.manage')` 和 `@ApiBearerAuth()` 统一鉴权与 Swagger 文档标注；`users.service.ts` 封装所有业务逻辑，依赖 `PrismaService` 直接操作 `user` 表，并调用 `RolesService` 校验角色 slug。DTO 定义集中在 `dto/user.dto.ts`，使用 class-validator 与 @nestjs/swagger 装饰器完成入参校验与 API 文档生成。服务层内部通过私有方法 `assertUsernameAvailable`、`assertEmailAvailable`、`assertNotLastAdmin`、`revokeSessions` 复用校验与会话失效逻辑，形成清晰的内聚边界。
