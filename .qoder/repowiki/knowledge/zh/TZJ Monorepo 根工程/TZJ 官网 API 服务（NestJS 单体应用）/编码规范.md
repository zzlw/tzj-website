- 每个业务领域独立一个目录（controller/service/module/dto），通过 @Module 声明并在 app.module.ts 中统一 import。
- DTO 使用 class-validator + class-transformer 装饰器进行请求校验，由全局 ValidationPipe 自动生效。
- 权限控制通过 auth 模块提供的 @Public、@Roles、@RequirePermissions 装饰器配合 JwtAuthGuard/RolesGuard 实现。
- 数据库操作统一通过 PrismaService 获取 PrismaClient，Service 层封装 CRUD 逻辑，Controller 仅负责参数校验与响应包装。
- 全局横切关注点（限流、鉴权、IP 封禁、审计、异常、响应格式）通过 APP_GUARD/APP_INTERCEPTOR/APP_FILTER 在根模块注入。
- 环境变量通过 ConfigModule + validateEnv 集中校验，敏感信息使用 common/crypto/secrets-crypto.ts 加密存储。
