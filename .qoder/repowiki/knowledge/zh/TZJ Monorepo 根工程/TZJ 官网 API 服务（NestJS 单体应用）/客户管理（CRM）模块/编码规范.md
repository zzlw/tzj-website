- Controller 方法统一使用 `@ApiBearerAuth()` 配合 `@RequirePermissions(...)` 装饰器声明接口鉴权，权限粒度按资源动作划分（view/manage/delete）。
- DTO 类通过 class-validator 装饰器（IsString/IsOptional/IsIn/ArrayMaxSize 等）+ `@ApiProperty` 同时完成运行时校验与 Swagger 文档描述。
- Service 中所有写操作均通过 `resolveContentAuthor(prisma, operatorId)` 填充 `lastOperator` / `createdBy` 等审计字段，保证操作溯源一致。
- 分页查询统一返回 `{ data, pagination: { page, limit, total, totalPages } }` 结构，排序字段通过白名单 `SORTABLE` 映射防止注入。
- 对关联用户（owner / lastOperator / createdBy）复用统一的 `CUSTOMER_INCLUDE` select 配置，避免重复定义字段集合。
- 幂等性通过显式判断实现（如 claim/release/transfer 中对 owner 相同或管理员场景直接返回原记录），而非依赖数据库唯一约束。
