模块采用 NestJS 标准分层：`access.controller.ts` 通过 `@Controller('access')` 暴露 REST 端点，统一使用 `@RequirePermissions` 装饰器做接口级鉴权；`access.service.ts` 仅作为薄封装转发到 `roles.service.ts`；`roles.service.ts` 是核心领域服务，负责与 `PrismaService` 交互完成 `accessRole`/`user`/`session` 表的读写，并在 `OnModuleInit` 中执行系统角色同步与废弃角色清理。`permissions.ts` 集中声明所有权限分组（`PERMISSION_GROUPS`）、角色-权限映射（`ROLE_PERMISSIONS`）及校验工具函数，是权限定义的单一事实来源。`dto/role.dto.ts` 使用 class-validator + swagger 注解描述请求体。模块通过 `@Global()` 标记并 `exports: [RolesService]`，使其他模块可直接注入 `RolesService` 获取角色权限信息，形成单向依赖：controller → service → roles.service → prisma + permissions。
