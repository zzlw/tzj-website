- 控制器方法统一使用 `@RequirePermissions('xxx.yyy')` 装饰器声明所需权限，读操作与写操作分别对应 `access.view` 与 `access.manage`。
- DTO 类统一使用 `class-validator` 装饰器（`IsString`、`MinLength`、`Matches`、`ArrayMinSize` 等）配合 `@ApiProperty` 生成 Swagger 文档。
- 权限定义集中在 `permissions.ts` 的 `PERMISSION_GROUPS` 数组中，新增业务模块必须在此扩展权限组，禁止在控制器或服务中硬编码权限字符串。
- 对系统预置角色（`isSystem: true`）的写操作统一抛出 `ForbiddenException`，自定义角色删除前检查是否仍有活跃用户关联。
- 涉及权限变更的操作（创建/更新角色、修改权限）后调用 `invalidateCache()` 清除内存缓存，必要时通过 `revokeSessionsForRole` 吊销相关会话强制重新认证。
