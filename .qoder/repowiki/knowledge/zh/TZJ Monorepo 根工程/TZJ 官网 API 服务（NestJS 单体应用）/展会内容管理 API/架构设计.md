模块采用 NestJS 标准三层结构：`trade-shows.controller.ts` 负责路由与请求校验（使用 `@Controller('trade-shows')`、`@ApiTags`、Swagger 装饰器），通过 `@Public()` 和 `@RequirePermissions('content.create|edit|delete')` 组合鉴权；`trade-shows.service.ts` 封装所有业务逻辑，依赖 `PrismaService` 直接操作 `tradeShow` 表，复用 `common/utils` 中的内容发布状态过滤、排序、Markdown 清洗、作者解析等通用工具；`trade-shows.module.ts` 作为 Nest 模块注册 Controller、Service 并导出 Service 供其他模块使用；`dto/trade-show.dto.ts` 使用 class-validator + @nestjs/swagger 定义输入校验与 OpenAPI 描述。依赖方向单向：Controller → Service → PrismaService + common 工具库，无反向依赖。
