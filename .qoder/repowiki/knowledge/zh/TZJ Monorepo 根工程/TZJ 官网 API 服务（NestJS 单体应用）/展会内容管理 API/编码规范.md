- Controller 方法统一使用装饰器声明路由、Swagger 元数据与鉴权：`@Public()` 用于公开接口，`@RequirePermissions('content.*')` + `@ApiBearerAuth()` 用于后台管理接口。
- DTO 类通过 `@Is*` 校验装饰器 + `@ApiProperty` / `@ApiPropertyOptional` 同时完成参数校验与 OpenAPI 文档生成，可选字段使用 `@IsOptional()` 标记。
- Service 层复用 `common/utils` 中的内容处理工具（如 `applyPublishedFilter`、`stripInternalContentFields`、`sanitizeMarkdown`、`resolveContentAuthor`、`applyContentEditorMetadata`），避免在领域服务中重复实现通用逻辑。
- 分页查询统一返回 `{ data, pagination: { page, limit, total, totalPages } }` 结构，并通过 `parseListSort` + `buildListOrderBy` 标准化排序参数。
- CRUD 操作中涉及 Markdown 内容的字段（`content`、`summary`）在写入前统一经过 `sanitizeMarkdown` 与 `generateDocumentSummary` 处理，确保数据安全与摘要一致性。
