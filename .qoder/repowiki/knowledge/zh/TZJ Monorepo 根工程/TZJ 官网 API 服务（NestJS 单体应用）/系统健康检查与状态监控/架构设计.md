模块由两个并列的 NestJS 子模块组成：`health` 负责底层依赖探测（数据库通过 PrismaService 执行 `SELECT 1`，存储通过 S3Service.ping，Redis 按 REDIS_URL 配置判断是否跳过，邮件通过 IntegrationsService.isActive），对外暴露 `/health`、`/health/live`、`/health/ready` 三个公开端点；`system` 依赖 `HealthModule` 导出的 HealthService，在 `/system/status` 中组合健康检查结果与 Node.js 进程信息（memoryUsage、os.loadavg、statfs 磁盘用量、APP_VERSION/package.json 版本）生成 SystemStatusResponse。依赖方向单向：SystemService → HealthService → PrismaService/S3Service/IntegrationsService/ConfigService，HealthModule 通过 exports 暴露 HealthService 供 SystemModule 消费。
