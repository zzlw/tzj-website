采用 NestJS 标准三层结构：`news.controller.ts` 暴露 RESTful 路由（`GET /news`、`GET /:slug`、`POST`、`PUT /:id`、`DELETE /:id`），通过 `@Public()`、`@ApiBearerAuth()`、`@RequirePermissions('content.create|edit|delete')` 等装饰器组合实现公开访问与后台鉴权；`news.service.ts` 封装所有业务逻辑，直接依赖 `PrismaService` 操作数据库，复用 `common/utils` 下的通用工具（`applyPublishedFilter`、`assertPublishedOrStaff`、`sanitizeMarkdown`、`generateDocumentSummary`、`resolveContentAuthor`、`applyContentEditorMetadata`、`buildListOrderBy` 等）；`dto/news.dto.ts` 使用 class-validator + swagger 注解定义输入校验与 API 文档；`news.module.ts` 作为模块入口，导出 `NewsService` 供其他模块复用。依赖方向单向：controller → service → prisma/common-utils，无反向依赖。
