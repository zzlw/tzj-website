- Controller 方法统一通过 `@ApiOperation` 描述摘要、`@ApiQuery`/`@ApiProperty` 标注参数，并由 `@ApiTags('news')` 归类到 Swagger 分组。
- 公开接口使用 `@Public()` 装饰器，后台写操作统一叠加 `@ApiBearerAuth()` 与 `@RequirePermissions('content.*')` 权限控制。
- DTO 字段通过 class-validator 装饰器声明类型与约束，并用 `@ApiProperty` 提供中文描述，`UpdateDto` 一律继承 `PartialType(CreateDto)`。
- Service 层复用 `common/utils` 中的通用函数处理发布状态过滤、Markdown 清洗、作者解析、编辑元数据注入等横切逻辑，避免在业务层重复实现。
- 分页查询统一返回 `{ data, pagination: { page, limit, total, totalPages } }` 结构，排序通过 `parseListSort` + `buildListOrderBy` 白名单校验后生成。
