采用 NestJS 标准三层结构：`cases.module.ts` 通过 `@Module` 声明控制器与提供者，并导出 `CasesService` 供其他模块复用；`cases.controller.ts` 暴露 `/cases` 路由，使用 `@Public()` 开放列表与详情，其余写操作通过 `@RequirePermissions('content.create|edit|delete')` + `@ApiBearerAuth()` 保护；`cases.service.ts` 封装所有业务逻辑，依赖 `PrismaService` 直接操作 `case` 表，并通过 `../common/utils/*` 下的通用工具完成发布过滤、排序、Markdown 清洗、作者解析与元数据注入；DTO 层位于 `dto/case.dto.ts`，使用 class-validator 校验字段，UpdateCaseDto 通过 PartialType 派生。依赖方向严格单向：Controller → Service → Prisma + common utils，无反向依赖。
