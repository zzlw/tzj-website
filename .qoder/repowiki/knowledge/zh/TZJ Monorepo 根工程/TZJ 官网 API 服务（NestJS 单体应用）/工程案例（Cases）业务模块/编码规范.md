- Controller 方法统一通过装饰器声明 API 文档：`@ApiOperation` 描述用途，`@ApiQuery`/`@ApiProperty` 标注参数与字段说明。
- 鉴权采用组合装饰器模式：公开接口用 `@Public()`，后台写操作统一叠加 `@RequirePermissions('content.*')` 与 `@ApiBearerAuth()`。
- DTO 字段同时标注 Swagger 的 `@ApiProperty` 与 class-validator 校验装饰器，可选字段使用 `@IsOptional()` 包裹。
- Service 中的复杂查询通过组合 `../common/utils/*` 下的通用函数（如 `applyPublishedFilter`、`parseListSort`、`sanitizeMarkdown`、`resolveContentAuthor`）实现横切关注点复用。
- 错误处理统一抛出 `NotFoundException` 并附带中文消息，保持对外错误信息一致性。
