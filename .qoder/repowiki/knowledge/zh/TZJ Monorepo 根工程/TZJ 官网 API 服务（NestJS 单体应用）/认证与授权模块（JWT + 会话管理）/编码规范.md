- 所有路由级鉴权通过装饰器注入元数据（`@Public`、`@RequirePermissions`、`@Roles`），由对应 Guard 统一读取判断，而非在控制器内手写逻辑。
- DTO 统一使用 class-validator 装饰器（`IsString`、`MinLength`、`MaxLength`、`IsEmail`、`IsOptional`）配合 `@ApiProperty` 完成输入校验与 Swagger 文档生成。
- 敏感操作（登录失败、登出、密码修改等）通过统一的 `audit` 方法写入 `auditLog` 表，失败时仅记录警告日志而不中断主流程。
- 刷新令牌采用 SHA-256 哈希后存入 session 表，避免明文存储，并通过 `rotatedToHash` 与 `graceUntil` 字段实现轮换竞态安全处理。
- 角色与权限解耦：`Role` 常量集中定义于 `roles.ts`，权限集合通过 `RolesService.getPermissionsForSlug` 动态解析，Guard 中只比较权限 slug 而非直接比对角色名。
