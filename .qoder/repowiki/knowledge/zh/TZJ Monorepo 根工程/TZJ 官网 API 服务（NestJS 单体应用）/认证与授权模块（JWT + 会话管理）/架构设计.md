模块以 `auth.module.ts` 为装配入口，注册 `AuthController`、`AuthService`、`JwtStrategy`，并导入 `ConfigModule`、`PassportModule`、`JwtModule`；`AuthService` 是核心业务层，封装登录、刷新、登出、资料修改、密码变更与会话管理等全部逻辑，依赖 `PrismaService` 读写数据库、`RolesService` 解析角色权限、`JwtService` 签发/验证 JWT。

- 策略层：`strategies/jwt.strategy.ts` 继承 `PassportStrategy(Strategy)`，从 Bearer Header 提取 JWT，拒绝 refresh 类型令牌用于资源访问，并通过 Prisma 校验用户状态。
- 守卫层：`guards/jwt-auth.guard.ts` 扩展 `AuthGuard('jwt')`，结合 `@Public()` 元数据实现「公开路由可选鉴权、受保护路由强制鉴权」；`guards/roles.guard.ts` 读取 `@RequirePermissions` 与 `@Roles` 元数据，调用 `RolesService.getPermissionsForSlug` 做细粒度权限判定。
- 装饰器层：`decorators/` 下四个装饰器通过 `SetMetadata` 注入元数据（`IS_PUBLIC_KEY`、`PERMISSIONS_KEY`、`ROLES_KEY`），配合 `CurrentUser` 参数装饰器从 `request.user` 注入当前用户。
- DTO 层：`dto/auth.dto.ts` 与 `dto/profile.dto.ts` 使用 class-validator + swagger 注解定义请求体校验。
- 类型定义：`roles.ts` 集中声明 `Role` 常量、`AuthUser` 与 `JwtPayload` 接口，被 service、strategy、guard 共同引用。

依赖方向：controller → service → (prisma, rolesService, jwt)；guard/strategy 仅依赖 reflector、config、prisma，不反向依赖 controller。
