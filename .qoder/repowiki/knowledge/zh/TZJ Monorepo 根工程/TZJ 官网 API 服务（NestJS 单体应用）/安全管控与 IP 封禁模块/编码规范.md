- 控制器方法统一使用 `@ApiBearerAuth()` 配合 `@RequirePermissions(...)` 权限装饰器进行鉴权，并通过 `@ApiOperation` / `@ApiQuery` 生成 Swagger 文档。
- 分页查询统一返回 `{ data, pagination: paginateMeta(...) }` 结构，复用 `../analytics/utils/analytics-list` 提供的 `paginateMeta`。
- IP 相关操作先通过 `normalizeIp` 标准化，再用 `hashIp(ip, salt)` 生成不可逆标识，原始 IP 以 `maskIp` 脱敏存储。
- 服务类通过构造函数注入 `PrismaService` 和 `ConfigService`，并使用 `private readonly` 字段声明依赖。
- DTO 校验使用 class-validator 装饰器（`IsString`、`IsOptional`、`IsIn`、`MaxLength`），枚举值集中定义常量数组。
