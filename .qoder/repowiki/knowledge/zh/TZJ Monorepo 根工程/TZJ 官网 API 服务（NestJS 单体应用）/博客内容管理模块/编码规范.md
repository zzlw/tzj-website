- 控制器方法通过 `@Public()` 标记公开接口，通过 `@RequirePermissions('content.*')` + `@ApiBearerAuth()` 保护后台写操作，读操作统一使用 `@CurrentUser()` 注入用户以区分公开/后台场景。
- DTO 使用 class-validator 注解（`IsString`、`IsOptional`、`IsEnum`、`MinLength`、`MaxLength` 等）配合 `@ApiProperty` 生成 Swagger 文档，`UpdateBlogDto` 通过 `PartialType(CreateBlogDto)` 派生。
- Service 层复用 `common/utils` 中的通用工具函数处理发布状态过滤、排序构建、字段脱敏、作者解析、元数据注入等横切逻辑，避免重复实现。
- 错误处理统一抛出 `NotFoundException` 并附带中文消息，包含被查找的资源标识（slug 或 id）。
