采用 NestJS 标准三层结构：`blogs.controller.ts` 负责 HTTP 路由与参数校验（使用 `@Controller('blogs')`），`blogs.service.ts` 封装业务逻辑并直接调用 `PrismaService` 操作 `blog` 表，`blogs.module.ts` 通过 `@Module` 声明控制器、服务及导出依赖。DTO 定义在 `dto/blog.dto.ts` 中，使用 class-validator 注解进行请求体验证。权限控制通过 `@Public()`、`@ApiBearerAuth()` 和 `@RequirePermissions('content.create|edit|delete')` 装饰器组合实现，区分公开访问与后台编辑场景。分页、排序、搜索等通用能力复用 `common/utils` 下的工具函数（如 `parseListSort`、`applyPublishedFilter`、`stripInternalContentFields`）。
