- Controller 方法通过 `@RequirePermissions`、`@ApiBearerAuth`、`@Public` 等装饰器声明鉴权与 Swagger 元数据，公开接口使用 `@Public()` 而非移除认证装饰器。
- DTO 字段统一使用 `@ApiProperty` / `@ApiPropertyOptional` 描述 Swagger，配合 `class-validator` 装饰器（`IsString`、`IsEmail`、`MinLength`、`MaxLength`、`IsBoolean`、`IsOptional`）完成输入校验。
- Service 中对可选字符串参数使用 `nullableTrim` 辅助函数将空串归一为 null，避免入库无意义值。
- 列表查询通过白名单 `SORTABLE` 映射前端排序 key 到 Prisma 字段，防止排序注入。
- 对外暴露的复杂数据结构（如 `ContactListEnrichment`、`ContactVisitorProfile`）以 TypeScript interface 定义，并在 service 内部构造时填充默认空值（如 `EMPTY_PROFILE`）。
- 跨模块服务注入时，对无需 DI 的服务（如 `IpLocationService`）直接在当前模块 providers 中声明，避免引入整个上游模块造成耦合。
