采用标准 NestJS 分层结构：`contact.controller.ts` 暴露 REST 路由并通过装饰器声明 Swagger 文档与权限控制；`contact.service.ts` 封装业务逻辑，使用 Prisma 直接操作 `contact`、`customer`、`visitor`、`page_views` 等表，并通过 `aggregateLastIp` / `pickLatestIp` 等工具函数聚合访客行为数据；`contact.module.ts` 作为模块入口，通过 `@Module` 注册控制器与服务，显式 import `IntegrationsModule` 和 `NotificationModule`，并以 provider 形式注入 `IpLocationService`（避免跨模块耦合）。DTO 定义在 `dto/contact.dto.ts`，使用 class-validator + class-transformer 做请求校验与转换。依赖方向单向：Controller → Service → PrismaService + 外部服务（AliyunCaptchaService、NotificationService、IpLocationService），无反向依赖。
