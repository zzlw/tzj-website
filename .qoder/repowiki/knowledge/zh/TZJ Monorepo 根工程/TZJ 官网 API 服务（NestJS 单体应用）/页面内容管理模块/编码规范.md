- Controller 方法通过装饰器组合声明权限：只读接口使用 `@Public()`，写接口统一叠加 `@RequirePermissions('<action>')` 与 `@ApiBearerAuth()`。
- Service 层对数据库查询结果进行空值检查，找不到记录时直接抛出 `NotFoundException` 并附带中文消息。
- DTO 使用 `@nestjs/swagger` 的 `ApiProperty` / `ApiPropertyOptional` 配合 class-validator 装饰器（`IsString`、`IsOptional`、`MinLength`、`MaxLength`、`IsEnum` 等）同时完成入参校验与 API 文档生成。
- 富文本字段在创建和更新时统一经过 `sanitizeRichText` 工具函数处理后再写入数据库。
