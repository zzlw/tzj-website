采用标准 NestJS 分层结构：`pages.module.ts` 作为模块入口声明 `PagesController` 与 `PagesService` 并提供 Service 导出；`pages.controller.ts` 通过 `@Controller('pages')` 暴露 CRUD 路由，使用 `@Public()` 开放只读接口，通过 `@RequirePermissions('content.create|edit|delete')` + `@ApiBearerAuth()` 保护写操作；`pages.service.ts` 封装 Prisma 数据访问，调用 `PrismaService` 对 `page` 表执行 findMany/findUnique/create/update/delete，并在不存在时抛出 `NotFoundException`；`dto/page.dto.ts` 定义 `CreatePageDto` 与基于 `PartialType(CreatePageDto)` 的 `UpdatePageDto`，使用 class-validator 校验字段并借助 `@nestjs/swagger` 的 `ApiProperty` 生成文档。依赖方向单向向下：Controller → Service → PrismaService，DTO 仅用于入参校验与 Swagger 描述。
