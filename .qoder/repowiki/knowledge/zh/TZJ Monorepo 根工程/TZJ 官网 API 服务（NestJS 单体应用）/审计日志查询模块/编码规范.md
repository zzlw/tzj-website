- Controller 层仅负责参数解析与转发，业务逻辑全部委托给 Service，保持职责单一。
- 查询参数统一使用 `@Query` 装饰器配合 `DefaultValuePipe` 和 `ParseIntPipe` 进行默认值与类型转换。
- Prisma 查询通过独立的 `buildWhere` 方法动态拼装条件，避免在调用处重复拼接 where 逻辑。
- 分页返回统一包含 `data` 与 `pagination`（page、limit、total、totalPages）结构。
- 排序字段通过白名单常量（如 `AUDIT_SORT_FIELDS`）限制，结合 `parseListSort` 工具函数保证安全性。
