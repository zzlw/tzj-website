- 对外暴露的 HTTP 接口统一使用 `@ApiTags`、`@ApiBearerAuth()` 和 `@RequirePermissions` 装饰器进行文档化与权限控制。
- 查询参数统一通过 `@Query` + `DefaultValuePipe` + `ParseIntPipe` 组合进行默认值与类型校验。
- 异步任务通过 `setImmediate` 包裹并在 `.catch` 中记录错误，避免阻塞主请求流程。
- 所有可重入操作均通过 `idempotencyKey` 在数据库中做幂等检查，防止重复发送。
- 邮件模板同时提供 HTML 与纯文本两个渲染函数，并对用户输入统一使用 `escapeHtml` 转义。
