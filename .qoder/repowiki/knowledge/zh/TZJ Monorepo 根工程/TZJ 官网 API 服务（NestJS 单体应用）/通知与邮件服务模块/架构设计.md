采用标准 NestJS 模块结构：`notification.module.ts` 作为入口，通过 `@Module` 声明导入 `IntegrationsModule` 和 `SettingsModule`，并导出 `NotificationService` 供外部使用。`NotificationController` 仅暴露一个受权限保护的 GET `/notifications/logs` 接口用于分页查看通知记录。核心业务集中在 `NotificationService`：通过 `dispatchContactCreated` 使用 `setImmediate` 异步派发询盘通知，内部根据站点设置决定是否启用、调用 `AliyunDmService` 发送邮件，并通过 Prisma 的 `notificationLog` 表实现幂等（`idempotencyKey`）与状态追踪（pending/sent/failed）。`retryFailedNotifications` 使用 `@Cron(EVERY_10_MINUTES)` 定时任务在 24 小时内重试失败邮件。模板渲染逻辑独立放在 `email/templates/contact.templates.ts`，为每个模板提供 HTML 与纯文本双版本，并使用内联样式保证邮件客户端兼容性。依赖方向单向向外：本模块依赖 `integrations`、`settings`、`prisma`，不反向被它们依赖。
