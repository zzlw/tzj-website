- 每个第三方集成以独立 service 文件命名（`<provider>.service.ts`），并通过常量 `SLUG` 声明 slug，再在 `INTEGRATION_REGISTRY` 中集中注册元数据。
- 敏感凭据一律通过 `IntegrationsService.resolveSecret(slug, fieldKey)` 获取，公开/半公开配置通过 `resolveConfig` 获取，禁止直接访问 Prisma 或 ConfigService 读取凭据。
- 集成启用状态统一通过 `IntegrationsService.isActive(slug)` 判断，该函数会检查 DB 记录是否 enabled 且所有 required 字段均已配置（支持 DB + env 双重来源）。
- 连接测试逻辑以 `IntegrationTester` 函数形式注册到 `INTEGRATION_TESTERS` 对象中，返回 `{ ok: boolean; message: string }` 的统一结构。
- Controller 中所有写操作均先通过 `z.object(...).safeParse` 校验请求体，失败时抛出 `BadRequestException` 并附带 `error.flatten()` 详情。
- 管理员接口返回的 secrets 一律使用 `maskSecret` 脱敏展示，原始值仅存在于 `secretsEnc` 加密字段中，不随响应泄露。
