采用 NestJS 标准三层结构：`analytics.controller.ts` 暴露 REST 端点（公开采集接口 `collect`/`identify` 使用 `@Public()` + `@Throttle` 限流，管理端查询接口统一加 `@RequirePermissions('analytics.view')` + `@ApiBearerAuth()`）；`analytics.service.ts` 承载核心业务逻辑，通过 Prisma 直接执行 `$queryRaw` SQL 完成复杂聚合与分页；`ip-location.service.ts` 独立封装 IP 归属地解析（纯真库离线主源 + ip-api.com/ipapi.co 在线补充，进程内 Map 缓存 7 天）。模块依赖 `SettingsModule`（读取 geoMode）、`IntegrationsModule`（获取高德 webKey）、`SecurityModule`（IP 封禁检查），依赖方向单向向外，不反向被其他模块引用。`dto/` 目录用 class-validator 定义入参校验，`utils/` 按职责拆分工具函数（client-ip、geo-ip、traffic-source、key-pages、ua-parser、geo-label/reverse/list 等），SQL 片段集中在 `analytics-list.ts` 中通过 Prisma.Sql 拼接，避免控制器层散落查询逻辑。
