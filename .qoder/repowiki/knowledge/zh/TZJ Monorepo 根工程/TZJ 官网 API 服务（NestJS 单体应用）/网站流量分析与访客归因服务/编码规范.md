- DTO 字段统一使用 `@ApiProperty`/`@ApiPropertyOptional` 描述 Swagger 文档，配合 `class-validator` 装饰器（`IsString`、`MaxLength`、`MinLength`、`IsEmail` 等）进行入参校验，并通过 `Type(() => Number)` 处理数值转换。
- 所有列表查询接口遵循统一的 `page`/`limit`/`from`/`to`/`sortBy`/`sortOrder` 参数约定，排序子句通过 `analytics-list.ts` 中的 `*OrderClause` 函数生成 `Prisma.Sql`，分页元数据通过 `paginateMeta` 统一返回。
- 时间范围解析统一由 `parseRange` 函数处理，缺省 `from` 回退到 6 天前，`to` 缺省为当前时间，并以 `startOfDay`/`endOfDay` 对齐日期边界。
- 对外部服务的调用（IP 归属地、高德坐标反查）均采用 try/catch 包裹并返回 null 或空对象作为降级结果，保证主流程不因上游失败而中断。
- 敏感字段（IP、邮箱、电话等）在入库前进行掩码或哈希处理（`maskIp`、`hashIp`），且查询结果中优先返回掩码版本以保护隐私。
- 导入非类型依赖时使用 `// biome-ignore lint/style/useImportType` 注释说明原因（NestJS DI 需要运行期类而非类型导入），保持代码风格一致性。
