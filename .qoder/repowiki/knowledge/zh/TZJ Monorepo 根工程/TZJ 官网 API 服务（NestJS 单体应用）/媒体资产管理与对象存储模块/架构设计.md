模块按 NestJS 标准分层组织为两个子模块：
- `storage/`：底层存储抽象层，`StorageModule` 仅暴露 `S3Service`，通过 `@aws-sdk/client-s3` 同时适配本地 MinIO 与阿里云 OSS，凭 endpoint/env 自动切换 PathStyle/VirtualHostedStyle，并提供 upload/delete/getUrl/presignedUrl/copy/list 等原子操作。
- `media/`：业务编排层，`MediaModule` 依赖 `StorageModule` 和 `SettingsModule`，由 `MediaController` 暴露 `/api/media` REST API，`MediaService` 协调 Prisma 持久化、`S3Service` 存储、`WatermarkService` 图像处理以及 `MediaGuardService` 的引用保护检查。
- 依赖方向单向向下：`media` → `storage` + `prisma` + `settings`；`storage` 不反向依赖 `media`。
- `site-static-paths.ts` 集中维护站点静态资源清单，被 `MediaGuardService` 缓存为 Set，用于判断素材是否为不可删除的站点固定 key 资源。
- `watermark.service.ts` 使用 sharp 处理图片（SVG 叠加/平铺/居中/角落布局）并通过 child_process 调用 ffmpeg 处理视频水印，失败时静默回退原文件。
