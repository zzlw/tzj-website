- 控制器方法统一使用 `@ApiTags`、`@ApiOperation`、`@ApiBody`、`@ApiConsumes` 等 Swagger 注解描述接口，文件上传接口通过 `FileInterceptor` 配合 `limits.fileSize` 限制大小。
- 权限控制统一通过 `@RequirePermissions('media.*')` 装饰器声明，只读列表接口无需权限，写操作均需显式授权。
- DTO 类使用 `@ApiProperty` / `@ApiPropertyOptional` 配合 `class-validator` 的 `IsString`、`IsOptional`、`MaxLength` 进行参数校验与 OpenAPI 文档生成。
- 异常抛出采用 NestJS 内置异常类型（`BadRequestException`、`ConflictException`、`NotFoundException`）并附带结构化 error 字段，便于前端统一处理。
- 服务间依赖通过 NestJS `@Injectable()` 构造函数注入，模块通过 `exports` 显式导出共享服务（如 `S3Service`）。
