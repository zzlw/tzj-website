模块以 `src/index.ts` 为唯一对外导出入口，按功能域在 `src/components/` 下组织每个组件为一个独立子目录（如 `button/`、`dialog/`、`data-table/`），每个子目录包含一个主 `.tsx` 文件和一个 `index.ts` 重导出文件，便于按需引用。
- 基础样式通过 `src/lib/utils.ts` 中的 `cn` 函数（clsx + tailwind-merge）统一合并 className，所有组件均通过 `class-variance-authority` 定义 `*Variants` 并暴露给外部。
- 状态与主题由 `src/theme/ThemeProvider.tsx` 提供，使用 React Context 管理 dark/light 主题并持久化到 localStorage。
- Hooks（如 `use-mobile.ts`）与工具函数（`date-utils.ts`、`utils.ts`）放在同级目录下，供组件复用。
- 构建通过 `tsconfig.build.json` 开启 `declaration` 与 `declarationMap`，输出到 `dist/`，`package.json` 的 `exports` 字段同时暴露 ESM 入口与 `globals.css`。
- 依赖方向单向：组件 → hooks/lib → 第三方库（Radix、Tailwind、Sonner 等），组件之间不互相依赖，仅通过 `@tzj/ui` 入口聚合。
