- 每个组件独立成目录，包含同名主文件（如 Button.tsx）与 index.ts 重导出文件，再通过 src/index.ts 统一聚合导出。
- 组件 Props 接口继承原生 HTML 属性（如 ButtonHTMLAttributes<HTMLButtonElement>）并结合 class-variance-authority 的 VariantProps 类型，同时暴露对应的 *Variants 常量。
- className 合并统一通过 `cn(...)` 工具函数完成，禁止直接使用 clsx 或 tailwind-merge。
- 需要 ref 透传的组件一律使用 React.forwardRef 包装，并设置 displayName 以便调试。
- 客户端组件通过 `'use client'` 指令显式标注，服务端渲染安全的逻辑保持在纯函数或 hooks 中。
- Context 消费 hook（如 useTheme）在使用前校验 context 非 undefined 并抛出明确错误信息。
