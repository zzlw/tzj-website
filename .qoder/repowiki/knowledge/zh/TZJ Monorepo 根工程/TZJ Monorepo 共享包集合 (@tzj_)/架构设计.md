packages 目录按职责拆分为五个独立 npm 包，彼此通过明确的依赖边界协作：
- types（@tzj/types）作为最底层契约层，集中定义 DTO、实体、枚举、请求/响应类型，被 ui、dnd、theme 等上层包引用。
- config（@tzj/config）提供跨应用的 Zod 环境变量校验与 tsconfig 基线，供所有子包复用构建与运行时环境约束。
- theme（@tzj/theme）输出品牌设计令牌常量，被 ui 和 dnd 在样式与布局中消费。
- dnd（基于 dnd-kit）封装可排序树能力，仅依赖 types 中的共享类型。
- ui（@tzj/ui）作为面向业务的前端组件库，依赖 theme 的 token 与 types 的类型定义，并通过单一 index.ts 聚合导出所有组件。
各包均遵循 package.json + tsconfig.build.json 的标准 monorepo 包结构，由根级包管理器统一编排版本与发布。
