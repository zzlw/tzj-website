- 环境变量 schema 采用「基础 schema + 应用域 extend」的分层模式，所有应用共享 baseEnvSchema，再各自扩展特定字段。
- 每个 schema 都通过 `.parse(process.env)` 在模块加载时立即校验，失败即抛出异常，确保启动期发现缺失或非法的 env。
- schema 定义后同步导出对应的 `z.infer<typeof xxx>` 类型别名（如 BaseEnv、ApiEnv），使消费方获得完整类型推断。
- tsconfig 以独立文件形式发布，通过 package.json `exports` 映射到 `./tsconfig/*` 路径，供其他包按需引用。
