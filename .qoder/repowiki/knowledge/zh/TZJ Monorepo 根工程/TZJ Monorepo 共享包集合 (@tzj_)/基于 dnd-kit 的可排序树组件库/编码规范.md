- 组件采用 headless 模式：UI 结构完全由 `renderItem` render prop 决定，组件只负责拖拽状态与投影计算，保持通用可复用。
- 对外 API 通过独立的 `types.ts` 集中声明接口与类型，组件与工具函数均从该文件 import 类型，避免重复定义。
- 纯逻辑全部抽离到 `utilities.ts` 中的无副作用函数（如 `getProjection`、`computeSiblingIds`、`collectDescendantIds`），便于单元测试与跨组件复用。
- 拖拽相关状态（activeId、overId、offsetLeft）集中在组件内 useState 管理，并在 `resetState` 中统一清理，包括 document.body.cursor 恢复。
- 所有导出项在 `src/index.ts` 中显式 re-export，包括组件、类型（使用 `export type`）和工具函数，形成单一公开 API 边界。
