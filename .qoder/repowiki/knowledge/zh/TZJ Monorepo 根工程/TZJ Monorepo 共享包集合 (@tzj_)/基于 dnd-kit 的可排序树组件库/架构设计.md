模块以 React 函数组件为核心，采用「headless 组件 + 纯函数工具」的分层设计：
- `SortableTree.tsx` 是唯一的 UI 入口，内部通过 `DndContext` + `SortableContext` 组合指针/键盘传感器，使用 `DragOverlay` 渲染拖拽占位，并通过 `renderItem` render prop 将样式与内容完全交给消费方。
- `types.ts` 集中定义扁平节点 `FlatNode`、回调事件 `SortableTreeMoveEvent`、渲染参数 `RenderItemArgs` 与组件 props `SortableTreeProps`，构成对外契约。
- `utilities.ts` 提供纯函数：`getProjection`（根据水平位移计算目标深度与父级）、`arrayMove`（数组重排）、`collectDescendantIds`（后代 id 集合用于环路检测）、`computeSiblingIds`（同类型兄弟节点 id 列表），不依赖任何外部状态。
- `index.ts` 作为包入口统一 re-export 组件、类型与工具函数。
依赖方向单向：组件 → 工具函数；工具函数仅依赖类型定义，无循环引用。
