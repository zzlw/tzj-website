- DTO 采用 Create/Update 配对模式：每个实体的 UpdateDto 通过 `extends Partial<CreateXxxDto>` 复用创建字段，仅保留可选更新属性。
- 实体统一继承 `BaseEntity` 接口，包含 `id: string`、`createdAt: Date`、`updatedAt: Date` 三个公共字段。
- 枚举定义后紧跟同名的 `*Labels` 常量，类型为 `Record<EnumType, string>`，提供中文展示标签。
- 查询参数接口以通用 `QueryParams` 为基础，通过 `extends QueryParams` 扩展领域特定字段。
- API 响应统一使用泛型 `ApiResponse<T>` 包裹，分页场景通过 `PaginatedResponse<T>` 继承并补充 `pagination` 元数据。
- 各子目录通过 `index.ts` 聚合导出，再由根 `src/index.ts` 统一 re-export，对外仅暴露单一入口。
