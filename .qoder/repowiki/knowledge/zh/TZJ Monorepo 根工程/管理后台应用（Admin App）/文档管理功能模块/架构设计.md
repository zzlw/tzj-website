模块采用 Next.js App Router 的分页路由结构：`layout.tsx` 作为服务端入口统一校验会话与 `docs.view` 权限；`documents/` 下按资源划分 `new/`、`[id]/edit/`、`mine/` 等页面，每个页面仅做薄壳组合，核心 UI 逻辑下沉到 `components/documents/` 中的可复用组件。
- 路由层：`DocumentsHub` 作为列表入口，通过 `config.basePath` + `staticListParams` 注入不同视图（如 mine=1）；`DocumentEditorPage` 复用 `ResourceEditor` 完成新增/编辑。
- 组件层：`DocumentListView` 负责分页、搜索、排序、标签筛选与行操作；`DocFolderSidebar` 基于 `@tzj/dnd` 的 `SortableTree` 实现文件夹树拖拽、批量预取文档并拍平为扁平节点；`DocumentReadView` 展示正文与版本历史；`DocumentTagsManageDialog` 提供标签 CRUD/合并/重命名。
- 数据层：所有 API 调用通过 `@/features/documents` 暴露的 hooks（`useDocFolderTree`、`useMoveDocument`、`useDocTags` 等）与 `@/features/hooks` 的 `useList`/`useRemove` 完成，类型由 `DocumentsResourceConfig` 与 `InternalDocumentItem` 约束。
- 依赖方向：页面 → 组件 → features hooks → `@tzj/ui` / `@tzj/dnd`，不直接调用 fetch，保持单向依赖。
