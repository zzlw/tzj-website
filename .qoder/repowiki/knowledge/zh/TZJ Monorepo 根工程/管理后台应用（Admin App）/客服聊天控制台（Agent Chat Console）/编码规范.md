- 所有组件文件顶部使用 `'use client'` 指令，区分客户端组件与服务端渲染边界。
- Socket 事件通过 `ChatAgentEventMap` 类型强类型约束，`on/off` 方法以泛型形式注册监听器，避免字符串事件名散落在各处。
- HTTP 请求统一走 `api.ts` 中的 `request<T>` 封装，通过 `fetch` 调用 `/api/bff` 路径，禁止直接拼接外部 API URL。
- 状态更新普遍采用 `setX(prev => { ... })` 的函数式更新模式，配合 `ref.current` 快照（如 `bucketsRef`、`searchRef`、`selectedIdRef`）避免闭包过期问题。
- 防闪烁策略贯穿模块：unread 计数使用 `recentUnreadBumpRef` 时间窗口、`displayedTotalUnread` 非对称防抖、`mergeRooms` 保留对象引用等手段避免 UI 抖动。
- URL 查询参数（bucket/mine/room）通过 `window.history.replaceState` 同步到地址栏而不触发 RSC 请求，保持路由与状态双向一致。
