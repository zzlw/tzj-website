采用 Next.js App Router 的 `(dashboard)` 路由组，按业务域拆分为 `users/`、`access/`、`security/` 三个并列目录，每个目录通过独立的 `layout.tsx` 作为服务端权限守卫：`users/layout.tsx` 校验 `users.manage` 权限，`access/layout.tsx` 复用 users 的守卫，`security/layout.tsx` 校验 `security.view` 或 `security.manage` 权限。

页面层（`page.tsx`）仅负责路由装配与 UI 组合，具体交互逻辑下沉到 `components/{users,access,security}/` 下的可复用组件：`UserEditor.tsx` 复用同一组件处理新建/编辑两种场景；`RoleFormDialog.tsx` 以 Dialog + PermissionMatrix 形式呈现角色权限矩阵；`IpBlockPanel.tsx` 封装封禁表单、已封禁列表与高频 IP 流量表。

数据层统一通过 `@/features/hooks` 中的 `useList/useCreate/useUpdate/useRemove` 等自定义 Hook 调用后端 REST API，配合 `@/lib/use-url-state` 将分页、搜索、日期区间等状态持久化到 URL 查询参数，实现可分享、可刷新的过滤视图。UI 组件全部来自 `@tzj/ui`，图标使用 `lucide-react`。
