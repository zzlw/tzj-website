- 路由级权限校验统一放在同目录 `layout.tsx` 中，通过 `getSession()` + `apiFetch('/auth/me')` + `hasPermission()` 在服务端完成重定向守卫。
- 客户端页面统一使用 `'use client'` 指令，并通过 `@/lib/use-url-state` 将分页、搜索、筛选等状态序列化到 URL query，保证刷新后状态不丢失。
- CRUD 操作统一通过 `@/features/hooks` 提供的 `useList/useCreate/useUpdate/useRemove` 等 Hook 发起请求，成功/失败分别调用 `notifySuccess` / `notifyError` 反馈给用户。
- 表格列定义采用 `DataTableColumn<T>` 数组模式，主标识列设置 `pinLeft: true`，操作列设置 `pinRight: true`，确保横向滚动时关键信息可见。
- 敏感操作（删除、封禁等）统一通过 `ConfirmDialog` 二次确认，并在提交期间展示 `isPending` 加载态。
- 权限控制同时采用服务端 layout 守卫与客户端 `<Can perm="...">` 组件双重保护，确保前后端一致。
