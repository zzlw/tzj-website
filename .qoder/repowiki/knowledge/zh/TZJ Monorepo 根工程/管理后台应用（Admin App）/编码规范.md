- 页面路由遵循 Next.js App Router 约定，每个功能模块在 `(dashboard)/<feature>/` 下提供 layout.tsx 与 page.tsx，编辑页使用 `[id]/edit/page.tsx` 与 `new/page.tsx` 子路由。
- API 调用统一通过 `src/lib/apiClient.ts` 封装，BFF 代理集中在 `src/app/api/bff/[...path]/route.ts`，Socket 通信由 `useChatSocket` 等 hook 统一管理。
- 业务逻辑拆分为 `src/features/<domain>/` 目录，包含 types.ts、api.ts、hooks.ts 及 components/ 子目录，保持特性内聚。
- 通用 CRUD 页面通过 `src/components/crud/ResourceConfig` 声明式配置驱动，复用 ResourceListView 与 ResourceForm 完成列表与表单。
- 权限控制通过 `src/components/Can.tsx` 与 `src/features/access.ts` 中的角色/权限标识进行声明式门控。
