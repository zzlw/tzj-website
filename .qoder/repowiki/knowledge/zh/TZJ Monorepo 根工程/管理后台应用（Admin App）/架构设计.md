应用以 apps/admin 为根，采用 Next.js App Router 分层组织：
- `src/app` 定义路由结构，`(dashboard)` 分组承载所有后台页面，`api/` 下 BFF 代理（`bff/[...path]`）统一转发到后端，登录/登出、媒体上传等独立 API 路由。
- `src/components` 提供跨功能 UI 组件（CRUD、文档、媒体、安全、设置等），`src/features` 按业务域拆分特性（chat、contacts、resources、analytics、users/access/security、settings/integrations 等），`src/lib` 存放共享能力（apiClient、auth、tokenRefresh、notify、site-settings 等）。
- 各功能模块通过 `@tanstack/react-query` 钩子与 BFF 交互，聊天模块额外使用 socket.io-client 实时通信；认证基于 Cookie + BFF 的会话模式，权限通过 Can 组件与 access.ts 声明式控制。
- 构建产物为 standalone 输出，transpilePackages 引入 @tzj/ui、@tzj/types、@tzj/dnd 三个 workspace 包，Turbopack root 指向 monorepo 根目录。
