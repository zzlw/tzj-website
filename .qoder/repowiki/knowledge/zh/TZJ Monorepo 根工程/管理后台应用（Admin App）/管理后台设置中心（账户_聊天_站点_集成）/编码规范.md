- 设置页统一采用 `'use client'` 组件 + `useEffect` 同步服务端数据到本地 state，并通过 `patch(fn)` 纯函数更新不可变 form 对象。
- 所有异步操作通过 `@/features/*` 暴露的 React Query hooks（如 `useUpdate*`、`useUpload*`）发起，成功后调用 `notifySuccess`、失败调用 `notifyError` 提示用户。
- 需要权限控制的 UI 片段统一用 `<Can perm="xxx">` 包裹，读权限与写权限分别使用不同 perm 值（如 `integrations.view` 与 `integrations.manage`）。
- 图片/二维码类字段复用 `MediaPicker` 组件，上传前通过 `normalizeSocialQrForSave` / `watermarkImageKeyFromUrl` 等工具函数规范化 URL。
- 每个设置区块封装为独立 Card，并在 `CardFooter` 中使用统一的 `ModuleSaveButton` 组件展示保存按钮与 loading 状态。
- 服务端路由守卫在 `layout.tsx` 中集中处理，先 `getSession()` 再 `apiFetch('/auth/me')` 校验权限，失败一律 `redirect('/')`。
