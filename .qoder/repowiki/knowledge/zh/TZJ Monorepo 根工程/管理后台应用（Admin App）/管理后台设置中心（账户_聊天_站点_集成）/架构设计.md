模块基于 Next.js App Router 的 `(dashboard)/settings` 路由分组组织，每个子目录对应一个设置页：`account/page.tsx`（个人资料与密码）、`chat/page.tsx`（客服资料与在线时间）、`site/page.tsx`（联系方式、邮件通知、备案、访客分析、社交媒体、水印）、`integrations/layout.tsx+page.tsx`（第三方 API 密钥与配置）。`integrations/layout.tsx` 作为服务端布局守卫，通过 `getSession()` 和 `apiFetch('/auth/me')` 校验 `integrations.view` 权限后渲染子路由。页面全部为 `'use client'` 客户端组件，数据获取与提交统一通过 `@/features/*` 中的 React Query hooks（如 `useSitePublicSettings`、`useUpdateIntegration`、`useFavicon`），UI 组件来自 `@tzj/ui`，权限控制通过 `<Can perm="...">` 包裹。可复用的设置卡片（`FaviconSettingsCard`、`WatermarkSettingsCard`、`ScreenWatermarkSettingsCard`）放在 `components/settings/` 下，以受控 props（value/onChange/pending/onSave）形式被 `site/page.tsx` 组合使用，形成「页面负责表单状态 + 卡片负责具体字段」的分层结构。
