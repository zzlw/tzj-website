模块以 Next.js App Router 的两条路由为入口：`app/(dashboard)/analytics/page.tsx` 聚合概览与趋势图表，`app/(dashboard)/visitors/page.tsx` 通过 Tabs 切换 `PeopleVisitorLens` 与 `IpVisitorLens` 两个「lens」视图。图表渲染集中在 `components/analytics/AnalyticsCharts.tsx`（基于 recharts 的 TrendChart/DonutChart/HorizontalBarChart），设备列复用 `device-columns.tsx`。数据获取统一来自 `@/features/analytics` 的 React Query hooks（`useAnalyticsOverview`、`useAnalyticsVisitors`、`useAnalyticsVisitorDetails`、`useAnalyticsIpActivity` 等）。全局命令式抽屉由 `visitor-drawer/VisitorDrawerProvider` 提供，通过 `context.ts` 暴露 `openPerson/openIp/close` API，实现 IP 抽屉与人物抽屉的有限栈（封顶 2 层）桥跳转，并同步到 URL 参数 `?ip=` / `?person=` 实现深链可分享。权限校验在两个 layout 中通过 RSC 调用 `/auth/me` 并检查 `analytics.view`。导出功能走 `@/features/analytics-export` 的 CSV 下载。
