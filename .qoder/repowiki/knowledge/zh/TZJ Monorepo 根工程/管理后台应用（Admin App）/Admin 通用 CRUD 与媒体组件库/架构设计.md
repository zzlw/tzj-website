模块按职责划分为三个子目录与若干独立组件：
- `crud/`：以 `config.ts` 中 `ResourceConfig<T>` + `FieldDef` + `FieldType` 为核心配置契约，`ResourceListView` 负责分页、搜索、筛选（URL 状态持久化）与行操作；`ResourceEditor` + `ResourceForm` 通过 react-hook-form + zod 校验，根据字段类型动态渲染输入控件；`MediaPicker` 是独立的媒体选择弹窗，`MarkdownEditor` 封装 Vditor 并集成媒体上传。
- `media/`：`MediaCard`、`MediaPreviewDialog`、`media-utils.ts` 提供媒体卡片展示、预览对话框及工具函数（类型判断、文件大小格式化、下载/预览），被 `MediaPicker` 复用。
- 根级独立组件：`Can.tsx` 基于 `session.tsx` 的 `ClientSession` 上下文做客户端权限门控；`CopyableText.tsx` 提供带复制图标的文本；`RichHint.tsx` 解析 `[文字](url)` 语法。
依赖方向单向向下：CRUD 组件依赖 `@tzj/ui` 基础组件、`@/features/hooks` 数据钩子、`@/lib/*` 通知/配置；媒体组件仅依赖 `@/features/media` 与 `@/features/types`；`Can` 仅依赖 `session` 上下文。
