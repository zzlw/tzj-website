- 所有交互组件顶部标注 `'use client'`，服务端组件不直接包含这些文件。
- 权限控制统一通过 `<Can perm=.../>` / `<Can anyPerm={...}/>` 包裹 UI 元素，实际权限由 API 的 RolesGuard 强制，前端仅作展示层过滤。
- CRUD 页面通过声明式 `ResourceConfig<T>` 配置驱动，字段类型使用 `FieldType` 字面量联合类型，新增字段类型需在 `config.ts` 中扩展并在 `ResourceForm` 的 switch 分支中处理。
- 用户反馈统一走 `notifySuccess` / `notifyError`，错误信息通过 `error instanceof Error ? error.message : '未知错误'` 安全提取。
- 媒体相关组件通过 `getMediaKind(mimeType, filename)` 统一判断媒体类型，再分派不同渲染逻辑（image/video/audio/pdf/file）。
- 表单字段默认值与 slug 自动生成集中在 `ResourceForm` 内，通过 `autoSlug` 开关控制，slug 未填写时自动从 title 生成。
