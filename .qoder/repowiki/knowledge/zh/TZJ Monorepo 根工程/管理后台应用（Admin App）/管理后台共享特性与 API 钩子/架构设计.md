模块按职责分为三层：
- `lib/` 基础设施层：`apiClient.ts` 统一封装 REST 请求（list/get/create/update/remove/patch/post/put/query/del），`auth.ts` 提供服务端会话读取与 Bearer 调用，`tokenRefresh.ts` 实现进程内单飞 refresh，`fetch-retry.ts` 提供网络重试；`config.ts` 集中 BASE_PATH/API_BASE 等环境变量。
- `features/` 业务特性层：每个文件对应一个管理功能域（access、media、analytics-export、customers-import、chat/*、resources/* 等），通过 `@/lib/apiClient` 或各自专用 API（如 chat/api.ts）访问后端，并用 `@tanstack/react-query` 的 useQuery/useMutation 暴露 hooks。
- `hooks/` 纯 UI 钩子层：如 `useDebouncedValue`，无副作用仅处理状态。
依赖方向严格单向：features → lib，不反向依赖；chat 子目录自包含 types、api、socket hook 与组件，对外仅暴露 `useChatSocket` 与类型。
