- REST 资源操作统一通过 `@/lib/apiClient` 的 `api.list/get/create/update/remove` 等方法发起，queryKey 采用 `[resource, 'list'|'detail', params]` 命名约定。
- React Query mutation 的 `onSuccess` 中统一使用 `queryClient.invalidateQueries({ queryKey: [resource] })` 触发列表失效，保持缓存一致性。
- 错误对象统一继承 `ApiError` 并携带 `status`、`code`、`details` 字段，上层通过 `error.code` 分支给出用户可读提示。
- 服务端鉴权走 Next.js cookies 中的 `tzj_at`/`tzj_rt`，Bearer Token 由 `auth.ts` 的 `apiFetch` 自动注入，客户端直连 BFF 时通过 `/api/bff` 代理透传。
- Socket.io 事件契约通过 TypeScript 映射类型（如 `ChatAgentEventMap`）强类型约束 on/off 回调参数，避免字符串事件名散落。
- CSV 导入/导出采用「列定义数组 + value 提取函数」的配置模式（如 `COLUMNS`、`PEOPLE_EXPORT_COLUMNS`），配合 `escapeCell` 转义与 UTF-8 BOM 头保证 Excel 兼容。
