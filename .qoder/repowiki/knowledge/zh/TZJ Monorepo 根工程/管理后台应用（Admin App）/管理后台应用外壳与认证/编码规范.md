- 受保护路由统一在 `(dashboard)/layout.tsx` 中通过 `getSession()` 做服务端拦截，失败即 `redirect('/login')`，页面组件不再重复校验会话。
- 需要权限控制的 UI 通过 `hasPermission(permissions, 'xxx')` 判断后条件渲染，而非在路由层拦截，保证降级体验。
- 对外部 API 调用统一使用 `apiFetch` / `apiFetchFull`，失败时采用 try/catch + 空数组或默认值降级，不阻断页面渲染。
- 客户端组件顶部显式标注 `'use client'`，服务端组件通过 `export const dynamic = 'force-dynamic'` 强制动态渲染。
- Cookie 读写集中在 `app/api/auth/*` 路由中，使用 `cookies()` 配合 `COOKIE.access` / `COOKIE.refresh` 常量，且生产环境设置 `secure: true`。
