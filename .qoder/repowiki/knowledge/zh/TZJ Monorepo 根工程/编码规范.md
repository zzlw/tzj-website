- 所有子应用与包通过 pnpm workspace catalog 统一管理依赖版本，禁止在子包中重复声明 catalog 已覆盖的版本
- 构建与开发任务统一通过 turbo.json 声明，子包仅暴露 task 名称（build/dev/lint/typecheck/clean），不直接运行底层工具
- API 响应格式统一为 `{ code, message, data, pagination? }`，CORS 仅放行 web(3001) 与 admin(3002)
- 环境变量使用 zod 在启动时校验，.env.*local 纳入 turbo globalDependencies 确保缓存失效
