- 所有对外暴露的 Socket 事件名在 `ChatVisitorEventMap` 中统一定义，`on/off` 方法通过泛型强类型约束回调参数类型。
- HTTP 请求统一通过 `request<T>` 函数封装，自动注入 `Content-Type: application/json` 并设置 `cache: no-store`，错误时抛出带状态码的 Error。
- 副作用（定时器、事件监听、socket 连接）均在 `useEffect` 中创建并在返回的 cleanup 函数中清理，使用 `cancelled` 标志或 `ref` 避免异步回调在卸载后执行。
- 坐席可用性显示采用防抖策略：瞬时 away 先保持 online，超过宽限时间（如 90s）才降级为 away，避免用户切换标签页造成的抖动。
- UI 文案集中定义在组件内 `I18N` 对象中，按 `zh-CN` / `zh-TW` / `en` 三语键组织，通过 `useLocale()` 选择当前语言。
- 所有 React 回调使用 `useCallback([])` 稳定引用，hook 返回值通过 `useMemo` 包裹，避免消费方因新对象导致重复注册监听器。
