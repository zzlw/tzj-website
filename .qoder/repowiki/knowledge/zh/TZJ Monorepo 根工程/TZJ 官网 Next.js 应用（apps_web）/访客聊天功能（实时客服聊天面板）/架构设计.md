模块按职责分为两层：`features/chat/` 提供领域能力（HTTP API 封装 `api.ts`、Socket.io 连接与事件分发 `useVisitorChat.ts`、坐席可用性防抖逻辑 `presence.ts`、共享类型 `types.ts`），`components/chat/` 提供 UI 组件（主面板 `ChatWidget.tsx`、Markdown 渲染 `ChatMarkdown.tsx`、表情选择器 `EmojiPicker.tsx`）。依赖方向单向：组件层通过 hook `useVisitorChat` 调用 `api.ts` 和 `presence.ts`，不直接操作 socket；`useVisitorChat` 内部动态 `import('socket.io-client')` 实现懒加载，并通过 `ChatVisitorEventMap` 强类型约束事件契约。聊天面板采用「推送 + 轮询」双模型：Socket 负责实时消息与 presence，每 5s HTTP 拉取会话兜底一致性，REST 端点同时作为 socket 不可用时的降级通道。
