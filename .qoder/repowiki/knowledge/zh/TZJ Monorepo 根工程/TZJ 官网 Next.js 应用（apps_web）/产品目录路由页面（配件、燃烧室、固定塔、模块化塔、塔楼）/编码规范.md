- 每个页面文件顶部定义常量 HERO_IMAGE / HERO_VIDEO / RELATED_HREFS，用于 Hero 媒体和 RelatedLinks 的硬编码链接数组。
- 通过 `export async function generateMetadata()` 调用 `createPageMetadata({ namespace, path })` 声明页面的 SEO 元数据，namespace 与 i18n JSON 键一致。
- 页面组件为 `async` 函数，使用 `await getTranslations('pages.xxx')` 获取翻译函数，并通过 `t.raw('key') as Type` 强类型化获取结构化文案数据。
- 页面结构统一包含：Hero 区域 → Overview 区块 → StatBandI18n → ProcessBandI18n → RelatedLinks → CTA 区块，按固定顺序组合。
- JSON-LD 结构化数据通过 `<JsonLd data={[...]} />` 组件注入，使用 `breadcrumbJsonLd` 和 `productJsonLd` 工厂函数生成。
- 子分类页面通过 `RELATED_HREFS` 或内联 `relatedHrefs` 数组与父级页面建立双向导航关联，保持产品线内部链接一致性。
