每个产品线目录对应一个 `[locale]/<product>/` 路由段，采用 Next.js App Router 的 Server Component 模式：每个 `page.tsx` 作为独立页面组件，通过 `export async function generateMetadata()` 调用 `createPageMetadata` 生成 SEO 元数据；页面内容完全由 `next-intl/server` 的 `getTranslations` 驱动，所有文案从 i18n JSON 命名空间（如 `pages.accessories`、`pages.burnRooms`、`pages.fixedTower`、`pages.modularTower`、`pages.towers`）中读取，使用 `.raw()` 获取结构化数据并映射到 UI。子分类页面（如 `accessories/competition`、`burn-rooms/liner`、`fixed-tower/series` 等）遵循相同结构，复用共享组件：`MediaImage`、`SectionHeading`、`Container`、`RbButton`、`RbLink`、`VideoHero`、`StatBandI18n`、`ProcessBandI18n`、`RelatedLinks`、`JsonLd`，以及 SEO 辅助函数 `breadcrumbJsonLd`、`productJsonLd`。依赖方向单向向下：页面 → 共享 UI 组件 → `@/lib/i18n/metadata` 与 `@/lib/jsonld`。
