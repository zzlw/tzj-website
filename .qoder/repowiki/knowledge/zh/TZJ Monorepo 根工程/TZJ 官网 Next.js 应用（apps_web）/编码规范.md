- 页面路由统一放在 src/app/[locale]/<板块>/<页面>/page.tsx，通过 next-intl 的 useTranslations 读取 messages 下的 JSON 文案。
- 跨页面复用的 React 组件集中在 src/components/<分类>/ 目录，按功能域拆分（layout、content、products、search、sections、ui 等）。
- 数据模型与 API 封装放在 src/lib/ 下，按领域文件命名（如 blog.ts、cases.ts、product-catalog.ts），并通过 .d.ts/.js 同步导出类型。
- 环境变量驱动的远程资源域名（S3/OSS）通过 NEXT_PUBLIC_S3_PUBLIC_DOMAIN 注入 next.config.ts 的 images.remotePatterns，禁止硬编码。
- 构建期脚本通过 package.json scripts 统一编排，dev/build 前自动执行占位图生成与 vditor 资源复制。
