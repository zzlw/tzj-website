- 页面组件统一导出 async 函数作为默认导出，并通过同名的 generateMetadata 函数返回 Metadata 对象，SEO 元信息集中由 createPageMetadata 或 generateSeo 生成。
- 多语言文案通过 await getTranslations('namespace') 在服务端获取 t 函数，页面内文本一律经 t() 调用，静态数组用 t.raw() 直接读取翻译结构。
- 图片资源统一使用 MediaImage 组件并设置 fill、sizes、object-cover 等属性，封面图提取通过 pickCoverImage 工具函数处理。
- 页面底部统一复用 StatBandI18n、ProcessBandI18n、RelatedLinks、CtaBand 等区块组件，保持各业务页面视觉与交互一致性。
- 动态路由参数采用 Promise 类型声明（如 params: Promise<{ slug: string }>、searchParams: Promise<Record<...>>），并在函数体内 await 解构。
- 当 API 查询失败或找不到内容时，列表页以空状态 UI 兜底，详情页通过 notFound() 触发 Next.js 404 页面。
