模块采用 Next.js App Router 的双层结构：
- 页面层 `apps/web/src/app/[locale]/search/page.tsx` 是服务端渲染的搜索结果页，通过 `generateMetadata` 生成 SEO 元数据，使用 `next-intl/server` 获取翻译，并调用 `@/lib/search/run-search` 执行实际搜索。
- API 层 `apps/web/src/app/api/search/` 下按功能拆分路由：`route.ts` 返回分页搜索结果（GET）、`suggest/route.ts` 返回搜索建议（GET）、`analytics/route.ts` 接收搜索交互埋点（POST）。
- 所有路由共享同一套参数解析与国际化校验逻辑（从 URL searchParams 提取 q/locale/page/limit，并通过 `routing.locales` 校验 locale），业务核心统一委托给 `@/lib/search/run-search` 中的 `runSiteSearch` 和 `runSearchSuggestions`。
- 依赖方向单向向下：页面/API → lib/search → 组件（UI 与搜索专用组件位于 `@/components/search/*`），不反向依赖。
