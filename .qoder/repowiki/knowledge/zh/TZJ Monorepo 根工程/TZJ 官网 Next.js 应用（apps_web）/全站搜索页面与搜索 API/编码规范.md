- API 路由统一从 URL searchParams 解析 q、locale、page、limit 等参数，并通过 `routing.locales.includes(localeParam)` 校验 locale，非法时回退到 `routing.defaultLocale`。
- 所有 API 响应均设置 `Cache-Control: private, max-age=0, must-revalidate` 头部，禁止缓存敏感搜索结果。
- 分页参数统一做边界保护：page 取 `Math.max(1, ...)`，limit 取 `Math.min(48, Math.max(1, ...))`，默认 limit 为 12。
- 国际化文案通过 `getTranslations('search')` 在服务端异步获取，再传入组件使用。
- 搜索业务逻辑集中封装在 `@/lib/search/run-search` 中，页面与 API 仅负责参数解析与响应包装，不直接实现搜索算法。
