- 每个页面文件均导出 `generateMetadata` 函数，通过 `createPageMetadata({ namespace, path })` 或 `generateSeo({...})` 集中生成 SEO 元信息。
- 国际化文案统一通过 `await getTranslations('pages.*')`、`getTranslations('cta')`、`getTranslations('breadcrumbs')` 等命名空间获取，并在 JSX 中以 `t('key')` 形式使用。
- 列表页使用 `parseContentListState` + `buildListQuery` + `normalizePagination` 组合处理 searchParams 的分页、筛选与排序状态。
- 详情页通过 `fetchBySlug(getXxx, slug)` 模式获取内容，未找到时调用 `notFound()` 触发 404。
- 页面底部统一复用 CTA 区块（`<Container>` + `<RbButton href="/contact">bookConsult</RbButton>`）与 `RelatedLinks` / `StatBandI18n` / `ProcessBandI18n` 等共享区块组件。
- 图片渲染统一使用 `MediaImage as Image` 组件，配合 `fill`、`sizes`、`object-cover` 等属性实现响应式图片展示。
