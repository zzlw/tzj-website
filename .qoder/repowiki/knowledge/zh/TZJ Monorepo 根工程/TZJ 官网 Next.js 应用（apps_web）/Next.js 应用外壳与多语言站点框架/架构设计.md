模块以 Next.js App Router 为核心组织：
- `app/[locale]/` 为所有页面入口，通过 `[locale]` 动态段实现 zh-CN/zh-TW/en 三语前缀路由（`i18n/routing.ts` 中 `defineRouting` + `localePrefix: 'always'`）；根 `app/layout.tsx` 仅透传 children，实际 HTML/body/Providers 由 `[locale]/layout.tsx` 注入。
- 国际化通过 `next-intl/server` 的 `getRequestConfig`（`i18n/request.ts`）按请求 locale 加载对应 `messages/{locale}/**.json`，页面内使用 `getTranslations('common'|'contact'|...)` 获取 t 函数。
- `lib/` 集中站点级常量与数据层：`site.ts` 定义 `siteConfig`（公司名、联系方式、关键词等），`site-settings.ts` 通过 ISR（revalidate 300s）从 CMS API 拉取 `SitePublicSettings` 并与环境变量合并，`navigation.ts` 维护 `NAV_TREE` 导航树及 `buildNavItems` 转换函数，`product-catalog.ts`、`content-detail.ts`、`content-list.ts` 等提供内容模型类型与生成器。
- SEO 由 `lib/jsonld.ts`、`lib/seo.ts`、`app/sitemap.ts`、`app/robots.ts`、`app/manifest.ts` 统一处理。
- `app/api/search/` 暴露 `/api/search`、`/api/search/analytics`、`/api/search/suggest` 三个 Route Handler，供前端搜索组件调用。
- `hooks/useScrollHeaderHide.ts` 提供滚动隐藏顶栏的客户端 Hook，通过 `document.documentElement.dataset.headerHidden` 驱动 CSS。
- 依赖方向单向：页面 → lib 工具 → next-intl/messages，不反向依赖组件或 UI 库。
