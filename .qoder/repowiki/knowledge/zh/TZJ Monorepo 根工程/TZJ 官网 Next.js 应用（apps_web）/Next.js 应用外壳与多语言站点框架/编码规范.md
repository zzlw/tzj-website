- 页面路由采用文件系统约定式路由，每个目录一个 `page.tsx`，动态段用 `[slug]` 或 `[...path]` 命名。
- 国际化文案按功能域拆分为多个 JSON 文件（如 `pages/*.json`、`blocks.json`、`catalog.json`），通过 `getTranslations(key)` 在 Server Component 中按需加载。
- 站点配置优先从环境变量覆盖，其次回退到 CMS 返回的默认值，再回退到 `site-defaults.ts` 中的静态默认值，形成 env > CMS > defaults 的三层合并策略。
- 导航树以 `NavNode` 结构体声明（key + href + children），再通过 `buildNavItems(labelFor)` 转换为带 label 的 `NavItem[]`，label 来源与 i18n key 一一对应。
- 异步数据获取统一使用 `fetch` + `next: { revalidate, tags }` 实现 ISR，开发环境 revalidate=0，生产环境 revalidate=300。
- 客户端 Hook 使用 `'use client'` 指令并配合 `requestAnimationFrame` + passive scroll 监听优化性能，状态变更通过 `document.documentElement.dataset` 暴露给 CSS。
