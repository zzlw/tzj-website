模块按职责划分为六个子目录，形成自底向上的分层：
- `ui/index.tsx` 集中导出 Container、Eyebrow、SectionHeading、PageHero、VideoHero、RbButton、RbLink 等原子级 UI 组件，作为所有上层区块的视觉基础。
- `layout/` 提供站点级布局（Header、Footer、TopBar、HeaderShell）以及产品 MegaMenu，Header 通过 `@/i18n/navigation` 的 Link 和 `usePathname` 实现多语言路由，并集成搜索、语言选择器与滚动隐藏逻辑。
- `content/` 封装内容列表通用壳（ContentListShell、ContentListToolbar、ContentPagination），使用 Suspense 包裹 useSearchParams 以满足 Next.js 要求；MarkdownBody 基于 markdown-components 渲染富文本。
- `products/` 围绕产品线展示（ProductLinesGrid、ProductLineCard、ProductHubNav、ProductLineNav），数据来自 `@/lib/product-catalog` 并通过 `getLocalizedFamily/getLocalizedLines` 做 i18n。
- `sections/` 是营销区块集合（HeroSection、MissionSection、SolutionsSection 等），其中 `blocks.tsx` 定义无 i18n 的纯展示组件，`blocks-i18n.tsx` 通过 next-intl server-side `getTranslations` 注入文案后复用这些组件，体现“展示层 + i18n 包装层”的分离。
- `analytics/VisitorTracker.tsx` 监听路由变化调用 `trackPageView` 上报 PV。
- `i18n/` 通过 Context + dynamic import 暴露 LanguageSelectorProvider/useLanguageSelector，抽屉组件按需加载且 ssr: false。
依赖方向单向向下：layout/content/products/sections → ui → lib/utils；i18n 通过 next-intl/server 在服务端获取翻译，客户端组件通过 `useTranslations` 消费。
