- 展示型区块组件放在 `blocks.tsx` 中，i18n 文案通过独立的 `*-i18n.tsx` 文件用 `getTranslations` 组装后传入，保持展示与文案解耦。
- 客户端组件统一在文件顶部添加 `'use client'` 指令，服务端组件则通过 async 函数 + `getTranslations` 获取国际化数据。
- 样式统一使用 Tailwind 类名并通过 `cn` 工具合并 className，避免内联 style 对象。
- 链接统一使用 `@/i18n/navigation` 导出的 `Link`，而非原生 `<a>` 或 `next/link`，以保证多语言路由正确性。
- 可复用 UI 原子组件集中在 `ui/index.tsx` 导出，其他组件通过相对路径 `@/components/ui` 引入，不直接复制样式。
- 需要全局弹窗/抽屉状态（如语言选择器）通过 React Context + `dynamic(ssr: false)` 懒加载实现，避免 SSR 污染。
