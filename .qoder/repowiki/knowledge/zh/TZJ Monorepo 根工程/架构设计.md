根目录作为 monorepo 编排层：pnpm-workspace.yaml 声明 apps/* 与 packages/* 两个工作区，并通过 catalog 集中管理 Next.js、React、Tailwind、Zod 等跨应用依赖版本；turbo.json 定义 build/dev/lint/typecheck/clean/prisma 等任务及其依赖顺序（dependsOn: ["^build"]），由 package.json 顶层脚本统一入口（pnpm dev/build/lint/typecheck/db:*）；apps/web、apps/admin 通过 BFF 调用 apps/api 的 /api/v1 REST 接口，三者共同消费 packages/@tzj/* 中的类型与 UI 组件；infra 提供 Docker Compose 与 ECS/K8s 部署脚本，docs 集中 API/设计/ADR 规范，形成「前端双应用 + 单体后端 + 共享包 + 基础设施 + 文档」的分层架构。
