该模块为纯文档仓库，按主题划分子目录：`api/README.md` 描述 REST API 端点与统一响应格式；`brand/README.md` 定义 TZJ 品牌色板、字体与 Logo 使用规范；`design/` 下 `README.md` 规定排版体系、交互模式与间距，`tokens-web.md` 作为 Web 端 Design Tokens 的单一事实来源，引用 `packages/ui/src/globals.css` 与根 `AGENTS.md` 中的宪法级约束；`decisions/README.md` 以 ADR 格式记录技术栈选型、设计基准、代码质量与 CI/CD 部署策略；根目录 `TROUBLESHOOTING_FAVICON.md` 提供线上 Favicon 上传问题的排查步骤与修复清单。各文档之间通过相对路径交叉引用相关源码文件（如 `apps/api/Dockerfile`、`apps/admin/src/features/favicon.ts`），形成自包含的知识索引。
