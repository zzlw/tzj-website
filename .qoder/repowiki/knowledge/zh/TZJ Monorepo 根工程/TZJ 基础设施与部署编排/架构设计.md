模块按运行环境划分为三个子目录：
- `docker/`：核心编排层。`docker-compose.dev.yml` 启动 PostgreSQL 15、Redis 7、MinIO（S3 兼容）供本地开发；`docker-compose.prod.yml` 定义 api/web/admin/gateway/acme 五服务生产拓扑，通过 `--env-file` 注入 `.env.prod` 与 `.env.prod.local`，gateway 使用 nginx 模板 + acme 自动签发证书。
- `deploy.sh` 是 ECS 上的唯一部署入口，封装 docker login、Prisma migrate、滚动更新与健康检查；`deploy-local.sh` 提供本地构建→ACR push→SSH 远程部署的替代路径；`yunxiao/pipeline.yml` 将相同流程接入云效 Flow，三服务并行构建后由 VMDeploy 在 ECS 执行 deploy.sh。
- `k8s/README.md` 仅作为 Kustomize/Helm 结构规划占位，当前实际交付以容器镜像为主。
依赖方向单向：CI → ACR → ECS → compose/deploy.sh → 各服务容器，配置文件通过 `.env.*` 分层（非敏感 `.env.prod` + 密钥 `.env.prod.local`）。
